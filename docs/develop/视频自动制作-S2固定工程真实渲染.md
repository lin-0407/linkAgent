# S2：固定结构化工程真实渲染

## 范围与需求

S1 已交付多版本、运行与预算基础。本阶段解决结构化工程如何变成真实、可检查的媒体，不接自然语言生成、供应商配音、业务 worker 或发布流程。输入是明确的故事板身份、本地已生成音频、图片、实测时间线和字幕；输出为 MP4、SRT、封面、首中尾实际成片抽帧和最后生成的成功清单。

沿用总方案：Java 拥有业务状态和费用，Python renderer 只处理本地媒体。没有 HTTP API、业务数据库 Schema 或当前视频指针变更；不能把本阶段检查通过写成发布前完整试映已通过。

## 设计与实现

稳定入口位于 `renderer/linkagent_renderer`。`contract.py` 定义 RenderInputV1 和本地边界；`visuals.py` 使用受控图文构图及字体度量；`engine.py` 负责音频拼接、逐帧编码、进程取消/超时和结果核验；`__main__.py` 返回结构化退出结果。复用原型的 Pillow/NumPy、逐帧管道与 FFmpeg 思路，不导入原型剧情绘制，也不保留其 `.env`、HTTP 或 TTS 代码。

RenderInputV1 保存 runId、attemptId、storyboardId、固定 seed、完整 inputHash、输出媒体参数、带摘要的相对资产、连续场景和精确音频引用的 cue。键及字段严格校验，输入不能携带命令、二进制、字体路径或滤镜。实际契约及 CLI 示例见 [renderer/README](../../renderer/README.md)。

V1 使用直切，场景区间连续、左闭右开，总时长精确为总帧数除以帧率，没有转场重叠。不接受自由转场参数，后续加入时须重新定义计算公式和边界测试。图文支持全图、图文并排、文字卡和两项对比；图片轻微平移与固定缓动、强调线形成受控动画。

字体由 Docker 系统 Noto CJK 提供，通过 cmap 检查缺字；标题、正文和最多两行的字幕按实际字体宽度换行。越界直接拒绝，不静默缩小或裁切。背景亮度受限，正文与字幕使用高对比底板和独立安全区域。

音频为有来源的 16 位 PCM WAV，逐场景重采样到 48kHz 双声道，不变速、不截断。增益仅允许衰减并保留编码余量。字幕和独立 SRT 来自同一 cue，但本地检查不能独立证明原音频语义，需要上游提供核实过的文字。

## 资源和文件边界

输入、资产和输出均核对真实路径，拒绝越界软链接及 Windows/UNC 绝对路径。资产名不能使用隐藏文件或伪造 MIME；核对图片实际解码尺寸、PCM 参数与摘要。输出只写入全新尝试目录，失败不生成成功清单，已完成尝试不能覆盖。

限制包括 720p/1080p、24/25/30fps、全片最多 180 秒、单场景最多 30 秒、最多 48 场景、200 cue、64 资产、总资产 256MiB、单图 800 万像素。逐帧写出、单场景音频和单图片缓存，不预加载整片原始视频。编码输出与日志设上限，启动时检查磁盘余量。

CLI 有实际超时和 SIGINT/SIGTERM 取消；独立监控线程能终止阻塞的本次子进程。没有 Shell 拼接和通用进程清理。Python 审计钩子禁止网络和密钥文件，编码器使用最小环境与固定协议；验证容器再通过 network=none、内存、CPU、进程数及只读根文件系统提供实际资源边界。

## 成功条件与验证

FFprobe 核对真实编解码、尺寸、帧率、帧数、音轨、时长；FFmpeg 整片解码，检查解码后实际声音峰值、静音及削波，并从实际成片抽取首中尾画面。视频时长容差为一帧加 1ms，AAC 音轨和容器补齐容差为 65ms。素材渲染后再次校验摘要，清单记录字体摘要、版本及每个固定产物的大小和 SHA-256，最后原子写入 manifest.json。

验证包含危险路径、旧输出覆盖、媒体与摘要错误、时间线、字幕范围、缺字和溢出、真实编码失败、超时/取消、网络与密钥文件拒绝，以及三个不同主题的真实中文离线配音工程。命令、最终结果与未覆盖项见 [S2 验证记录](../error/视频固定工程渲染S2验证记录.md)。

S3 再接业务 worker、精确版本注册、OSS、探测、预处理和完整试映。本轮不提前开放自动制作入口，不复用测试音冒充真实供应商旁白。
