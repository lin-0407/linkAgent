# 前端 P0 用户化重构落地记录

## 目标

本轮按《LinkAgent 前端全链路用户化重构方案》落地 P0：把默认前端从开发者验证台改成面向 B 站 UP 主的视频发布与复盘助手。

## 范围

本轮只改前端信息架构、文案、可见性和基础样式，不新增后端接口，不修改数据库 Schema。

涉及文件：

- `src/App.vue`：一级导航改为创作台、参考案例、项目列表、设置。
- `src/components/CreatorWorkspace.vue`：创作台首屏、四步流程和开发者模式可见性。
- `src/components/KnowledgeWorkspace.vue`：参考案例页去技术化。
- `src/components/AgentFloatingWindow.vue`：AI 浮窗改为“问问 AI”。
- `src/components/SettingsDrawer.vue`：增加前端本地开发者模式开关。
- `src/components/ProjectListWorkspace.vue`：新增独立项目列表页。
- `src/components/MessageBubble.vue`：支持隐藏推理轨迹等诊断信息。
- `src/styles/theme.css`：统一 8px 容器圆角、首屏入口和高级设置样式。

## 关键设计

普通模式默认隐藏工作流消息、执行步骤、API 开销、评测样例、检索策略、索引状态等工程信息。这样用户先完成视频资料、发布方案、观众反馈、复盘报告四步，不需要理解后端 Agent 或 RAG 细节。

开发者模式使用 `localStorage` 保存前端开关，不改变后端响应结构。开启后仍可查看原有诊断能力。

项目列表独立成一级页面，但继续复盘时仍写入创作台既有本地状态键，避免为 P0 新增跨组件状态库。

## 验证重点

作者验证时重点检查：

1. 普通模式首屏只出现“开始优化一条视频”和“继续上次复盘”两个主操作。
2. 普通模式创作台只显示视频资料、发布方案、观众反馈、复盘报告四步。
3. 设置中开启开发者模式后，原有评测、开销、处理记录、索引状态仍可访问。
4. 参考案例页普通模式不展示检索增强、精排和索引状态。
5. 375px、768px、1440px 三档宽度无横向滚动和文本重叠。
