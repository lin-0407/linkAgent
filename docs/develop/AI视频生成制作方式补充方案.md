# AI 视频生成制作方式补充方案

日期：2026-10-20。作者已确认将可选 AI 视频生成融入创作业务：镜头可混用自有素材与 AI 生成画面，提供“全片采用 AI”的快捷选择，以短样片引导后续整片制作。作者进一步明确：暂缓具体模型选型，先实现功能，后续通过入口自行添加模型。模型选择不作为共用功能开发的前置；真实视频模型调用及配置页面尚未接入。

## 1. 用户看到什么

在制作蓝图中提供画面来源选择，沿用原任务和场景列表：

| 选择 | 画面来源 | 适用情况 |
| --- | --- | --- |
| 素材合成 | 用户图片/视频片段、内置图文，配合录音或 TTS | 录屏讲解、图文教程、使用已有素材 |
| AI 视频生成 | 视频模型生成实际视频片段，再统一编排、声音、字幕和导出 | 希望用生成画面表达故事或场景 |

作者已确认按镜头选择，并提供“全片采用 AI”的快捷操作。一个作品可以同时使用用户录屏、图片和 AI 生成片段；无需为混用新建第二条业务流程。“全片采用 AI”把所选故事板全部镜头切换为 AI 画面来源，展示变更范围和费用后再确认执行；它不承诺单次模型请求生成任意长度整片，也不顺带替换声音方案。

首版先跑通一个可配置接入协议，由部署者后续添加兼容的服务地址、模型标识和鉴权配置；业务不写死某一家模型，不把任意 URL 都视为兼容协议。具体配置入口随接入阶段实现，本轮不要求作者先选供应商。先看短样片是推荐路径；继续保留“直接制作整片”选择，样片不增加一道强制审批。

这里的“AI 视频生成”是调用真正的生视频模型，不把生成脚本、图片缩放或已有 `ProductionMethod.AI_GENERATION` 枚举当成此能力。现有枚举用于工作流分类，不能据此自动开启付费调用。

入口显示实际可用的模型、输出规格、输入材料、费用估算和本次上限。服务未配置或尚未通过验收时说明原因；不提供点击后才发现无法执行的制作承诺。

### 1.1 业务入口与确认

| 位置 | 用户操作 | 确认后的业务事实 |
| --- | --- | --- |
| 制作蓝图的场景卡片 | 选自有图片/片段，或“AI 生成这个镜头” | 该镜头的画面来源、实际素材引用或待生成要求 |
| 场景列表顶部 | “全片采用 AI” | 全部镜头来源变更的提案；执行前仍核对费用及输入材料 |
| 本次制作确认卡 | 查看镜头范围、声音、目标时长、实际模型、预计费用和上限 | 授权的故事板修订、生成范围与本次制作操作 |
| 样片结果页 | 播放/下载、重做指定镜头、继续制作整片 | 对准确样片或新整片操作执行，不覆盖旧视频事实 |

例如教程的第 1 镜头用 AI 演示概念，第 2–4 镜头用用户录屏，第 5 镜头用已有图片。只有第 1 镜头进入视频模型生成任务；重新生成开头时复用其余素材，最终合成为新版本。

切换选项本身只更新制作提案。尚未确认时不发送素材或提交付费任务；确认后按已授权范围连续执行，查询进度和存储结果不再反复要求确认。缺少自有素材或生成失败时明确给出补素材、重试或改来源的操作，不静默转用付费生成，也不拿旧片段冒充新结果。

## 2. 共用业务主线

```text
想法与材料 → 发布方向确认 → 制作蓝图：按镜头选画面与声音
→ 查看本次范围和费用 → 确认制作
    ├─ 自有素材镜头：准备实际素材
    └─ AI 镜头：按授权生成 → 保存实际视频片段
→ 同一工程合成短样片 → 播放/下载或修改 → 确认剩余整片范围和费用
→ 复用可用片段，补齐其余镜头 → 合成整片 → 实际试映 → 导出 → 用户实际投稿
```

具体页面可以整合确认动作，但不能用制作方式选择代替已有真实发布方案确认或费用授权。已选择素材合成时，不调用视频模型；切换到 AI 生成应重新计算影响范围和费用。

视频模型负责产生视频资产，FFmpeg 负责统一画幅、时间线、声音、字幕和最终文件。继续使用一个受控合成引擎，不另建一套视频版本、试映或发布后链路。

### 2.1 样片与整片的生成范围

先看样片时，只提交样片实际覆盖且尚缺素材的 AI 镜头，不能先付费生成全片再截取 10–15 秒。确认卡显示覆盖的镜头、预计生成用量和样片费用上限；若供应商最短生成时长超过所选范围，必须把实际计费范围说明白。

继续整片时复用仍符合当前故事板、参数和使用要求的 READY 片段，再生成未覆盖或已经修改的镜头。样片中的视频资产与剪出来的样片 MP4 分开保存；不能把样片 MP4 当成全部场景的可编辑原素材。样片的授权不会默认扩展为剩余整片的付费授权。

用户只重做某镜头时，本次提案明确涉及哪些素材、字幕、声音及费用；未变镜头继续复用，重新合成新视频版本。全片重新编码不等于再次生成所有 AI 镜头。

## 3. 时长、声音与修改

- 全片目标时长与单次模型任务时长分别保存，按实际可用规格安排镜头。不能承诺任意模型一次生成任意长度整片。
- 模型返回时长、帧率、音轨和画幅须实际探测；无法满足目标时给出调整提案，不静默变速、重复、截断对白来凑时长。
- 模型原声、用户录音、TTS 和 BGM 明确选择，避免生成对白与新增配音相互覆盖或叠加。
- 生成结果可复用为 VIDEO_CLIP 资产，走素材准备、规范化和 RenderInputV2；[S4a](视频自动制作-S4a视频片段合成基础.md) 已实现 V2 片段合成子集，素材上传、配置入口和供应商任务仍需继续接入。
- 修改某镜头时只对需要变化的镜头发起新的模型任务，之后重新合成视频版本；未变镜头、旁白和已验收素材复用。
- 供应商如无明确可用的局部编辑接口，修改按重新生成片段处理，不承诺恢复图层、精确改动某一帧或保持人物完全一致。

## 4. 真实异步任务与费用

提交前持久化任务、场景、参数快照、输入指纹、执行授权和费用预留。获得供应商任务 ID 后保存，后续查询该任务；刷新页面或重启不再发起同一笔生成。

任务查询与结果入库不能依赖前端轮询。生成成功后及时读取并校验实际媒体，保存到私有存储；供应商短期 URL 不作为永久资产，也不作为发布版本。

提交响应丢失且无法确认是否受理时保留未知费用与待核实状态。只有可验证的供应商幂等/查询依据才能恢复，不自动再次花费。取消本地任务不等于供应商一定取消或退款；迟到结果仍需记录归属与实际费用，但不能覆盖当前成片。

用户图片、录音、参考视频等发送到外部模型前，确认卡明确说明发送内容和用途；不因上传素材就默认授权外发。

技术核对来源（2026-10-20）：[阿里云万相 API](https://help.aliyun.com/en/model-studio/text-to-video-api-reference) 与 [火山方舟创建视频任务 API](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh) 均采用创建任务后查询结果的异步协议。此核对不等于已选定或已调用其中一家，也不将当前文档中的型号、价格或时长写成平台长期固定值。

## 5. 实施依赖与验收

生成范围已确认，作者已要求具体模型留给后续配置入口，不再为选型暂停共用功能开发。S3 的媒体调度/试映收尾与 S4 的素材、V2 工程按依赖推进；其中 V2 片段合成已在 S4a 落地。接入协议实现时核对实际请求、异步任务、支持规格和计费证据，按配置中的能力判断是否可用。

随后将模型配置入口、画面选择、能力查询、异步任务、费用和资产接入放入同一条实现范围。配置只向页面返回脱敏状态，不返回密钥；新增模型不会绕过本次制作授权。对外接口和 Schema 在相应接入阶段按实际协议形成契约，不以供应商品牌选型代替功能实施。

验收至少包括：

1. 同一故事板可以按镜头混用素材和 AI 画面，“全片采用 AI”准确展示变更；未配置模型时状态准确。
2. 素材合成不产生视频模型调用；AI 模式实际获得可播放视频。
3. 刷新、重启、重复点击、响应丢失不导致盲目重复付费。
4. 实际导入生成片段并制作样片/整片，输出对应准确版本。
5. 重做指定镜头时，其他已确认片段与配音被复用。
6. 取消、失败、短链接过期、私有存储失败和费用未知均有实际恢复证据。
7. 正式发布继续检查精确版本的完整试映，不把供应商任务成功写成 FULL 完成。
8. 先看样片只生成其覆盖的镜头，继续整片复用适用片段；变更指定镜头不重复生成未变镜头。
9. “全片采用 AI”不修改已选择的原声/用户录音/TTS；素材缺失或模型失败不会触发未授权的付费后备方案。

当前已落定业务方向并核对过官方协议，具体 API/Schema 仍随接入阶段评审；浏览器、真实供应商费用和实际生视频产物均未验收。S4a 的 VIDEO_CLIP 已有实际媒体与后台保存验证，不能将它写成已由视频模型生成或已有产品配置入口。
