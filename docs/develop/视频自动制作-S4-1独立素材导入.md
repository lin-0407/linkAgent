# S4-1 独立素材导入后端

日期：2026-10-21。基线 `be235ac`。承接[素材导入方案](视频素材导入与样片导出补充方案.md)，本轮解决用户素材无法独立上传、准备和恢复的问题。

## 需求与结果

图片、旁白录音、音乐和视频片段现在拥有独立 `assetId`，不创建 `DraftVideo`，不占成片版本号，不切换当前成片。任务处于想法准备阶段即可导入；导入不等于授权 ASR、TTS 或视频模型调用。

本轮交付后端上传、分片恢复、真实摘要校验、探测与规范化、私有短签读取、失败重试和取消清理。素材页面、故事板引用、字幕导入、BGM 混音、样片与 AI 生成继续在后续阶段实现。已准备素材暂不提供物理删除，避免故事板接入后破坏历史引用。

## 实现

新增 `creator.creation.asset` 模块。`CreationAssetController` 沿用 Jakarta Validation 和单人工作台 `default` 归属；`CreationAssetPersistence` 只处理短事务，外部存储和解码由独立后台线程执行。

统一 `init.sql` 新增三个实际使用的表：

| 表 | 用途 |
| --- | --- |
| `creator_creation_asset` | 素材身份、原始对象、声明与实测摘要、元数据、上传/准备状态、租约和失败原因 |
| `creator_creation_asset_part` | 分片序号、真实上传 ETag、登记字节数，供刷新恢复 |
| `creator_creation_asset_object` | PUT 前登记派生对象，保存清理屏障，失败或重启后仍能定位待删对象 |

状态链路：`CREATING → UPLOADING → COMPLETING → UPLOADED → PREPARING → READY`。后台失败进入 `FAILED`，保留失败阶段与受控中文说明，作者显式重试；取消进入 `CANCELLED` 并保留清理待办。

创建时冻结文件大小与完整 SHA-256。同一幂等键只有类型、文件名、大小和摘要一致才复用；文件名相同也可以用不同键创建独立素材。合并后检查 HEAD 大小，准备时流式读取实际文件重新计算摘要。扩展名与 MIME 声明均不作为可解码的证明。

上传片大小固定 8 MiB，最后一片按实际剩余大小校验。签名/登记复用原有分片请求 DTO，批量上限仍为 20。素材不经过 Spring 的整文件内存上传。

每次后台领取使用独立令牌、数据库时钟 300 秒租约和 10 秒心跳；只有活令牌能推进结果。过期操作可以接管，旧令牌不能发布 READY。新的准备尝试使用独立私有对象前缀，不覆盖原文件或旧尝试。素材调用限定在当前媒体服务已启用的部署，不改变自动制作的 `executionAvailable=false`。

## 真实媒体准备

`AssetMediaPreparer` 只接收后台下载到受控目录的本地普通文件，不接受用户 URL、命令和文件路径。固定解复用器，仅允许本地文件协议；子进程仅继承系统环境白名单。

| 输入 | 工作素材 |
| --- | --- |
| PNG、JPEG | 完整解码，按 EXIF 方向修正，生成 PNG 和 JPEG 缩略图；保留 PNG 透明度 |
| WAV、MP3、M4A | 完整解码为 48 kHz、16-bit、双声道 PCM WAV，保存原始/工作元数据 |
| H.264/HEVC 的 MP4、MOV | SDR、H.264/AAC、30 fps、方形像素工作视频和缩略图；规范化方向与可变帧率，保留唯一原声音轨，无声源仍无声 |

裸 AAC 在创建前拒绝，提示先封装为 M4A。HDR/BT.2020、高位深、未知像素格式、非直角旋转、多视频流、多音轨、独立字幕轨与不支持的音频编码返回明确原因，不能静默丢轨或改色。首发只支持单声道或立体声。

图片上传上限 30 MiB；音视频源上限 1 GiB、20 分钟、4K 像素范围。派生文件总量不超过 2 GiB。临时空间按源文件加 4 GiB 和 128 MiB 余量预检，涵盖派生文件和 GET 摘要复核副本。原生总超时复用 `creator.creation.renderer.timeout`，默认 600 秒。取消、超时、输出超限会回收本次进程及观察到的后代。

派生产物通过完整解码与格式/时长检查后上传，再 HEAD 和 GET 复核字节与 SHA-256，全部一致才发布 READY。FFmpeg 因文件大小限制提前结束不能算正常完成。

## 恢复与清理

素材使用有界的 S3 创建、合并、PUT 和 GET 请求，单请求含重试的总上限为 120 秒；原成片接口保持原调用参数。创建响应丢失后按准确私有对象键查询已有上传句柄并恢复，多余句柄撤销。

派生对象 PUT 前持久登记。结果不明时保留 180 秒屏障，防止在途写入尚未结束就确认删除；明确 PUT 成功后方可提前释放该对象屏障。清理时精确保留 READY 清单引用的对象与活租约对象。

取消先撤销分片并尝试清理，再等 180 秒做第二次存储核对；待办期间 `cleanupPending=true`。延期取消不会反复占满后台候选队列。清理失败仍保留数据库待办，不能只记录日志后丢失对象身份。

任务删除门禁增加未完成、失败和待清理素材。用户先取消并完成清理才能删除任务；READY 与原有媒体一样随任务逻辑删除保留历史。完整故事板引用查询和带影响说明的素材移除/物理删除仍属于后续阶段。

## API

统一前缀 `/api/creator/tasks/{taskId}/assets`，响应不含存储键、句柄、磁盘路径和永久公共地址。

| 方法与相对路径 | 输入/输出 |
| --- | --- |
| `POST /` | `Idempotency-Key`；`kind/fileName/contentType/fileSize/sha256`，返回素材快照 |
| `GET /?offset=0&limit=30` | 返回素材快照列表，包含上传/准备状态、失败原因、元数据和已登记分片 |
| `GET /{assetId}` | 刷新恢复同一素材 |
| `POST /{assetId}/parts:sign` | `partNumbers`，返回 10 分钟短签列表，`Cache-Control:no-store` |
| `POST /{assetId}/parts:complete` | `parts[{partNumber,etag,partSize}]`，原子登记并返回快照 |
| `POST /{assetId}:complete` | 校验所有分片已登记，后台合并并准备；重复请求不创建新素材 |
| `POST /{assetId}:retry` | 失败后从持久阶段显式恢复 |
| `DELETE /{assetId}` | 取消未完成素材并返回清理待办；READY 拒绝通过此入口删除 |
| `POST /{assetId}:read-url?role=NORMALIZED` | READY 私有读取，角色可为 ORIGINAL/NORMALIZED/THUMBNAIL；5 分钟短签，禁止缓存 |

READY 私有读取使用记录中的桶，检查对象仍存在且大小一致。重签不会重新解码或调用模型。上传未结束时存储桶配置变化会明确拒绝继续合并，避免跨桶写错。
