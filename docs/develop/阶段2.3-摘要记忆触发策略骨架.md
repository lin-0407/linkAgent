# 阶段 2.3：摘要记忆触发策略骨架

## 上下文

阶段 2.2 已完成短期记忆存储拆分，并支持进程内 Map / Redis 两种短期记忆后端。本轮不直接实现摘要压缩算法，只先搭建摘要记忆入口，让 `AgentExecutor` 有位置读取摘要上下文。

## 本轮变更

- 新增 `SummaryMemoryProperties`：管理摘要记忆开关与触发消息数配置。
- 新增 `SummaryMemory`：提供摘要读取、保存和触发判断入口。
- 修改 `AgentExecutor`：在最近对话前拼接 `Conversation summary`。
- 新增 `agent.memory.summary.*` 配置，默认关闭摘要记忆。
- 新增 `SummaryMemoryTest`：验证默认关闭、保存摘要和当前触发策略占位行为。

## 2026-05-24 补充

- 作者已完成 `SummaryMemory.shouldSummarize(sessionId, messages)`。
- 当前策略：摘要记忆开启且消息数超过 `trigger-message-count` 时，调用 `ChatModel` 生成摘要并保存到当前 session。
- 测试补充了未达到阈值不触发、超过阈值触发并保存摘要两条路径。

## 验证方式

```bash
cd backend
mvn test -Dtest=SummaryMemoryTest
```
