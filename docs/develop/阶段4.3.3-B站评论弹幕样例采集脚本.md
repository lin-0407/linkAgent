# 阶段 4.3.3：B 站评论弹幕样例采集脚本

## 需求分析

目标用户是需要复盘单个视频反馈的 UP 主和内容运营者。

要解决的问题是：当前前端需要用户手动复制粘贴评论和弹幕，体验成本高。给定一个用户主动提供的 BV 号后，可以生成本地样例文件，再用于评论弹幕分析。

输入数据来源：

1. 用户主动提供的 BV 号或视频链接。
2. B 站公开视频页面可访问的评论与弹幕接口。

本阶段只做：

1. 本地 Python 脚本，按单个 BV 拉取限量评论和弹幕。
2. 评论区分主楼评论和回复评论。
3. 弹幕保留分 P、播放时间和文本。
4. 输出 JSON 和 TXT，方便后续分析或人工检查。

本阶段不做：

1. 后端受控执行入口或定时任务。
2. 登录 Cookie、账号授权或风控绕过。
3. 批量 BV 采集。
4. 数据直接入库。
5. 前端一键抓取。

## 设计方案

### 文件位置

```text
scripts/bilibili_feedback_fetcher.py
```

脚本放在 `scripts/` 下，而不是放进后端业务包。

原因是这次能力属于本地样例采集辅助工具，不应该把不稳定的外部网页接口直接绑定到核心业务闭环。

### 命令示例

```bash
python scripts/bilibili_feedback_fetcher.py BVxxxx
```

限量采集：

```bash
python scripts/bilibili_feedback_fetcher.py BVxxxx --max-comments 20 --max-replies-per-comment 5 --max-danmaku 200
```

### 输出目录

默认输出到：

```text
export/bilibili_feedback/
```

该路径以脚本所在项目根目录为基准，不受当前命令行所在目录影响。

输出文件：

```text
BVxxxx_feedback.json
BVxxxx_feedback.txt
```

`export/` 和 `exports/` 都已加入 `.gitignore`，避免真实样例数据误提交。

### 输出结构

JSON 顶层结构：

```text
video       视频基础信息
comments   评论区，包含 rootComments 和 replyComments
danmaku    弹幕区，按分 P 分组
warnings   采集过程中的限制或失败提示
```

评论结构：

```text
rootComments[]                主楼评论
rootComments[].replyComments  该主楼下的回复评论
```

弹幕结构：

```text
pages[].items[].progressText  弹幕出现时间
pages[].items[].text          弹幕内容
```

### 外部接口

脚本使用公开视频网页接口：

1. `x/web-interface/view`：通过 BV 获取 aid、cid 和分 P 信息。
2. `x/v2/reply`：获取主楼评论。
3. `x/v2/reply/wbi/main`：旧评论接口返回空时，使用带 WBI 签名的新版主评论接口。
4. `x/v2/reply/reply` / `x/v2/reply/wbi/reply`：获取主楼下的回复评论。
5. `x/v1/dm/list.so`：获取指定 cid 的 XML 弹幕。

这些接口不是项目自己的稳定契约，可能因平台策略变化而不可用。脚本会使用公开网页接口需要的 WBI 签名参数，但不使用 Cookie 或绕过账号权限；遇到访问限制时只报错或写入 `warnings`。

## 编码实现

本轮新增：

- `scripts/bilibili_feedback_fetcher.py`

本轮修改：

- `.gitignore`
  - 忽略 `export/`
  - 忽略 `exports/`
  - 忽略 Python 本地缓存

脚本关键能力：

1. 支持 BV 号或包含 BV 的链接。
2. 支持 `--max-comments`、`--max-replies-per-comment`、`--max-danmaku` 控制规模。
3. 支持 `--page` 和 `--all-pages` 控制弹幕分 P。
4. 支持 `--delay` 控制分页请求间隔。
5. 旧评论接口为空时自动回退到 WBI 新版评论接口。
6. 标准库实现，不新增 Python 依赖。

## 测试验证

已执行：

```bash
python -m py_compile scripts/bilibili_feedback_fetcher.py
python scripts/bilibili_feedback_fetcher.py --help
python scripts/bilibili_feedback_fetcher.py not-a-bv
python scripts/bilibili_feedback_fetcher.py BV16F411S72L --max-comments 10 --max-replies-per-comment 3 --max-danmaku 0 --format json
```

验证结果：

1. Python 语法编译通过。
2. CLI 帮助命令正常输出。
3. 非法 BV 会输出清晰错误，不再暴露 Python traceback。
4. 实测视频旧评论接口返回空时，WBI 新版评论接口可以拉到主楼评论和回复评论。

作者验证真实 BV：

```bash
python scripts/bilibili_feedback_fetcher.py BVxxxx --max-comments 10 --max-replies-per-comment 3 --max-danmaku 100
```

成功标准：

1. 生成 JSON 和 TXT。
2. JSON 中 `comments.rootComments` 与 `replyComments` 分层清楚。
3. JSON 中 `danmaku.pages[].items` 包含弹幕时间和文本。
4. 若平台限制访问，脚本应报错或在 `warnings` 中说明，而不是尝试绕过。
