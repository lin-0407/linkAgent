# S3a：后端调用固定工程渲染器

本步解决 S3 的第一个接入问题：Java 后端如何调用 S2 的真实离线渲染器，并接收可核验、归属明确的产物。复用 `RenderInputV1`，不增加模型调用、付费调用、数据库表或公开 API。

## 需求和设计

输入是后续 worker 准备的本地工程，以及该 worker 已持有的 runId、attemptId、storyboardId、inputHash。输入必须位于部署工作根目录的 `runId/attemptId/` 内；输出固定为其中的 `rendered/`，每次尝试使用新目录，拒绝复用已有输出。

新增 `creator.creation.render`：部署配置、Java 进程桥接、清单验收和本地结果契约。命令按固定参数数组执行，不经过 shell；解释器、模块、字体和媒体工具来自部署配置。子进程不继承数据库、存储、模型等密钥，只保留系统运行所需环境变量。

等待期间检查取消、线程中断、超时和输出上限。终止时回收本次启动的进程树，不操作其他媒体任务。退出码非零时不能接收遗留清单；退出码为零后仍核对本次业务身份、工程文件是否变化、全部文件长度和 SHA-256、媒体参数和本地质量检查事实。

配置前缀 `creator.creation.renderer`，默认 `enabled=false`，现有部署行为保持不变。尚未接入持久化 worker，因此运行查询仍显示 `executionAvailable=false`，不新增会排队却无人消费的页面入口。

## 验证范围与实际结果

- 在同时含 Java、Python、FFmpeg、中文字体的隔离容器内，由 Java 真正启动 Python 渲染并验收结果。
- 验证取消、超时、编码失败、输出超限和进程树清理。
- 验证归属不符、陈旧输出、文件篡改、缺失文件、越界/软链接、错误媒体事实及部署密钥环境隔离。
- 回归现有运行、版本和媒体门禁；不调用真实供应商或改动作者现有数据。

已完成：269 项后端测试通过，0 失败、0 错误、0 跳过；包括新增 47 项和真实隔离 MySQL 55 项。Java 真正重渲染并接收已有 84.167 秒中文配音工程。完整命令、协议替身边界和首次离线依赖失败见 [验证记录](../error/后端渲染桥接S3a验证记录.md)，用法和制作原理见 [接入说明](../reference/后端固定工程渲染接入说明.md)。

## 当前边界

本地渲染产物尚未自动上传 OSS、注册业务视频版本、关联处理/试映子任务。完整 S3 仍需后续接入和验收；本步的成功不能标记 FULL 运行完成，也不能代替完整试映。
