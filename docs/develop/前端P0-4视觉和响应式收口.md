# 前端 P0-4 视觉和响应式收口

## 需求结论

P0-4 解决创作台在视觉和移动端上的收口问题。

本轮只调整前端表现层，不新增后端接口，不修改数据库 Schema，也不改变现有业务流程。

## 目标用户和场景

目标用户是 B 站内容创作者。

典型场景是作者在电脑或窄屏设备上使用创作台，按“视频资料、发布方案、观众反馈、复盘报告”四步完成一次视频发布与复盘。

## 本轮做什么

1. 在创作台流程栏增加移动端进度摘要。
2. 在移动端把流程导航收口为顶部进度条加横向步骤条，减少左侧栏挤占主内容的问题。
3. 统一创作台容器、按钮、结果块、任务项和过程步骤的圆角与触控高度。
4. 补齐 `min-width: 0`、自动换行和窄屏单列规则，降低 375px、768px 宽度下的横向溢出风险。

## 本轮不做什么

1. 不新增自动视频分析接口。
2. 不修改现有任务、发布建议、反馈分析和报告生成接口。
3. 不改变开发者模式的功能入口。
4. 不重写前端路由或状态管理。

## 设计说明

### 移动端流程表达

桌面端继续保留左侧流程栏，因为宽屏下它能帮助用户理解四步结构。

移动端新增 `.creator-mobile-progress`，用“第 N / 4 步 + 当前步骤名称 + 进度条 + 步骤说明”表达当前进度。

这样做是因为窄屏设备上如果继续展示完整左侧栏，主表单会被挤压，容易出现文字重叠和横向滚动。

### 触控目标

主要按钮、次级按钮、幽灵按钮、危险按钮、小按钮、步骤按钮和设置入口统一设置 `min-height: 44px`。

这样做是为了满足移动端点击目标最小尺寸要求，减少误触。

### 横向溢出收口

本轮对创作台主容器、结果块、表单网格和常见卡片补充 `min-width: 0`。

这样做是因为 CSS Grid 和 Flex 子项默认可能不收缩，长标题、长标签、长错误信息会把页面撑出横向滚动。

## 作者验证建议

开发者不执行编译、测试、构建、运行或启动命令。

请作者在本机执行以下验证：

```bash
cd frontend
npm run type-check
npm run build
```

预期结果：

1. 类型检查通过。
2. 前端构建成功。
3. 在 375px、768px、1440px 三档宽度下，创作台没有横向滚动、按钮不小于 44px、流程栏在移动端展示为顶部进度摘要。

如果失败，优先检查：

1. `CreatorWorkspace.vue` 模板中的 CSS 自定义属性绑定是否被类型检查器接受。
2. `theme.css` 末尾 P0-4 覆盖规则是否被更后面的样式覆盖。
3. 浏览器是否支持当前项目已经使用的现代 CSS 能力。
