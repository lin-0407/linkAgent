# 阶段 2.9 - 前端撞色艺术主题重构

## 本阶段目标

在不改动后端接口、不引入额外 UI 组件库的前提下，把前端首页从常规 Agent 聊天页重构为更适合作品集展示的 ReAct 工作台。

## 重构范围

- 将全局样式从 `App.vue` 中抽离到 `src/styles/theme.css`。
- 采用石榴红 `#E72D48` 与雾粉桃 `#F1DDDF` 作为主碰撞色。
- 保留少量墨色、青绿和金色作为工程感锚点，避免页面变成单一粉红主题。
- 重做侧边栏品牌区、会话区、状态指标、顶部统计、空态主视觉、消息气泡、ReAct 时间线和输入区。
- 不修改 `/api/agent/chat`、`/api/agent/sessions`、`/api/agent/sessions/{sessionId}` 接口契约。

## 当前实现位置

- 全局主题：`link-agent-frontend/src/styles/theme.css`
- 前端入口：`link-agent-frontend/src/main.ts`
- 首页编排：`link-agent-frontend/src/App.vue`
- 顶部统计：`link-agent-frontend/src/components/TopBar.vue`
- 左侧控制台：`link-agent-frontend/src/components/AgentSidebar.vue`
- 空态主视觉：`link-agent-frontend/src/components/EmptyState.vue`
- 输入区：`link-agent-frontend/src/components/ChatComposer.vue`

## 设计取舍

1. 本阶段没有引入 UI 组件库。
   当前目标是让项目首页先形成强识别度，额外组件库会增加样式覆盖成本，也会削弱页面的独特视觉语言。

2. 本阶段没有生成位图素材。
   首页的几何主视觉、纹理、斜切色块和动效都使用 CSS 实现，后续新增页面可以直接复用变量和布局语言。

3. 本阶段没有拆分更多业务组件。
   现有组件边界已经能表达首页结构，继续拆分会增加跳转成本。等增加记忆管理页、工具管理页、Trace 页面后，再按业务页面扩展。
