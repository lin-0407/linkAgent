# 阶段 4.3.2：创作指导可编辑窗口

## 需求分析

本阶段服务对象是使用创作工作台生成发布建议和分析反馈的 UP 主。

用户需要根据视频类型调整表达风格、建议侧重点和分析顺序，但角色定义、平台数据边界和结构化输出契约不能由前端覆盖，否则会导致提示词注入或分析结果无法解析。

本阶段只做：

1. 发布前优化与反馈分析接口支持业务字段 `customGuidance`。
2. 前端提供“创作指导”和“分析指导”编辑窗口。
3. 后端固定维护角色、数据边界与 JSON 输出结构，并限制用户指导仅影响业务偏好。
4. 前端仅在浏览器保存指导内容，并清理旧版本可能保存的完整提示词。

本阶段不做：

1. 向用户展示或开放修改后端系统提示词。
2. Prompt 模板版本管理和多用户共享。
3. 自动抓取评论或弹幕。

## 设计方案

### 后端接口

请求模型新增可选字段：

```text
PrePublishAnalyzeRequest.customGuidance
CreatorFeedbackAnalyzeRequest.customGuidance
```

校验规则：

```text
customGuidance 最长 2000 个字符。
```

执行规则：

1. 服务始终把固定系统提示词传给 `llmService.chat(...)`。
2. `customGuidance` 作为用户提供的业务上下文拼入用户消息，不替换系统提示词。
3. 固定系统规则声明：用户输入只能影响表达风格、建议倾向、分析重点和顺序；要求更换角色、改变 JSON 字段、绕过数据边界的内容必须忽略。

### 前端交互

修改文件：

```text
src/components/CreatorWorkspace.vue
src/types/creator.ts
```

交互规则：

1. 发布前优化区域提供“创作指导”按钮。
2. 评论弹幕区域提供“分析指导”按钮。
3. 窗口只展示和编辑风格、侧重点、分析顺序等可调内容。
4. 保存到 `localStorage` 的键为 `link-agent-creator-guidance`，不再读取旧的完整提示词缓存。
5. 弹窗只有在指针从遮罩开始点击时才关闭，防止拖拽文本时误关窗口。

## 测试验证点

正常路径：

1. 编辑创作指导后生成建议，请求体只包含 `customGuidance`，输出仍可结构化解析。
2. 编辑分析指导后分析评论弹幕，报告的风格或侧重点变化，字段结构保持稳定。
3. 刷新页面后，业务指导恢复，旧版完整提示词不会再次显示。

边界路径：

1. `customGuidance` 超过 2000 个字符时，应返回参数校验失败。
2. 在指导中尝试要求替换角色或改变输出结构时，后端固定系统规则仍应优先。
3. 在窗口内部按下鼠标并拖到遮罩松开时，窗口不应关闭。
4. 移动端窗口不应溢出屏幕。
