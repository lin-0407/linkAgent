# 阶段 4.3.1：创作工作台前端接入

## 需求分析

本阶段服务对象是正在本地联调的项目作者，以及后续演示时的面试官。

要解决的问题是：后端已经支持创作任务、发布前优化和评论弹幕分析，但没有前端入口时，只能靠接口工具测试，无法直观看到完整业务效果。

本阶段只做：

1. 新增创作工作台前端入口。
2. 支持创建任务、选择任务、查看材料。
3. 支持触发发布前优化并展示结构化建议。
4. 支持保存评论弹幕样例、触发反馈分析并展示报告。
5. 保留原 Agent 控制台，不破坏已有会话能力。

本阶段不做：

1. 前端路由复杂化。
2. 文件上传。
3. SSE 流式过程展示。
4. 图表分析。
5. 评论弹幕自动抓取。

## 设计方案

新增：

```text
src/types/creator.ts
src/api/creator.ts
src/components/CreatorWorkspace.vue
src/components/AgentConsole.vue
```

修改：

```text
src/App.vue
src/styles/theme.css
```

设计取舍：

1. `CreatorWorkspace.vue` 作为默认入口，方便直接测试 UP 主工作台闭环。
2. 原 `App.vue` 的 Agent 控制台逻辑拆到 `AgentConsole.vue`，避免新功能覆盖旧功能。
3. API 层统一封装错误读取，便于展示后端校验和 404/400 信息。
4. LLM 返回的 JSON 字符串字段在前端容错解析，解析失败时展示原文。

## 补充优化：输入体验与视觉统一

本次小改动服务于真实输入和项目演示两个场景：UP 主进入页面后应先看到清晰的输入路径，而不是已经写好的示例内容；同时创作工作台和 Agent 控制台应属于同一个产品。

本次只调整前端交互与样式，不改变接口结构、Agent 调用流程或数据来源边界。

实现取舍：

1. `CreatorWorkspace.vue` 的任务、偏好、反馈和可编辑指导初始值改为空字符串，避免样例内容被误认为真实输入。
2. 每个字段使用简短、低对比度的输入框内隐性提示，说明可输入的内容；提示只在空值时出现。
3. “创建任务”仅在至少输入一项稿件材料后可用，“保存样例”仅在评论或弹幕存在内容后可用，与后端 `@AssertTrue` 校验规则一致。
4. `theme.css` 延续 Agent 控制台的红黑纸面风格，以 B 站蓝和粉作为焦点、状态及标签辅助色，不把工作台改成单一平台配色页面。

## 测试验证点

正常路径：

1. 打开前端默认进入创作工作台。
2. 点击“创建任务”后，任务列表出现新任务。
3. 选择任务后，左侧显示任务材料。
4. 点击“生成建议”后，展示标题、简介、标签、卖点和风险。
5. 保存评论弹幕样例后，点击“分析反馈”展示反馈报告。
6. 顶部切换到 Agent 控制台后，原会话功能仍可使用。

边界路径：

1. 后端未启动时，前端展示请求失败信息。
2. 任务为空时，列表区域提示先创建任务。
3. 任务未选中时，发布前优化和反馈分析按钮禁用。
4. 后端返回未解析 JSON 时，前端仍展示 `rawOutput` 对应结果入口。
5. 未输入稿件材料时，“创建任务”按钮保持禁用。
6. 未输入评论或弹幕样例时，“保存样例”按钮保持禁用。
7. 移动端两列表单收为单列，框内提示不会挤压输入控件。
