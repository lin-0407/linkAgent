# S1：运行与预算基础

本轮解决同一创作任务的重复启动、取消与重试、失联执行器和费用透支问题。面向新手与小 UP 的目标仍是可靠制作视频；这里交付运行与记账基础，没有把准备结果或排队记录当成自动出片。

## 需求与边界

输入为明确的任务归属、预期工作区修订号、结构化请求、幂等键和人民币限额。输出为持久化运行状态、授权快照、租约代数与费用流水。预算初始化不授权消费。当前仅为后续协调器提供内部 TEXT/PREPARE 受理方法，整片、样片和修订运行尚未开放。

原有上传、试映、实际发布、BV 绑定和复盘链路继续使用；历史视频和报告不被本轮清空。已有人工流程的费用日志尚未全部归并，不能把本轮预算描述成整个任务所有入口的严格总账。

## 实现

在 `creator/creation` 中增加 `CreationRuntimeService`、`CreationRuntimeMapper`、最小数据契约和 `CreationRuntimeController`。工作区补活动运行指针、预算和初始化幂等身份；统一 `init.sql` 增加准备授权、运行、费用流水三张表及幂等补列。

- 同一任务的写入先锁任务，再按需锁版本。活动状态为 QUEUED、RUNNING、WAITING_DEPENDENCY、CANCEL_REQUESTED；运行表生成列唯一键作数据库兜底。
- 预算和运行写入在短事务中完成，事务内没有供应商调用。`startPreparation` 将准备授权和运行原子提交；既有授权启动及重试保留精确输入和限额。
- JSON 对象键排序后计算 SHA-256；拒绝重复键、尾随正文、空对象、超过 64 KiB 或层级超过 20 的输入。键顺序变化不重复创建；不是通用 JSON 语义等价算法。
- 启动以工作区修订号 CAS 受理；worker 使用活动运行身份和租约代数。预算变化不使仍有效的执行租约失效，心跳也不增加工作区修订号。
- 排队取消直接终止；运行中或等待依赖时只记录取消请求，仍占活动位置。执行器确认取消后才释放，失联取消由后续领取者接管。依赖等待释放租约并保留活动位置。
- 已发送的调用在取消、失败、租约接管后进入 UNKNOWN，继续占用原预留；未发送的预留释放。迟到真实费用允许在旧租约失效或运行取消后结算，但旧执行结果不能落成新结果。
- 调用前以 BigDecimal/DECIMAL(18,6) 同时检查任务余额和授权跨运行累计余额。重试和上调任务预算不会扩大原授权，零费用授权禁止付费预留。
- 全局唯一物理调用标识防止重复记账。适配器必须在真正发请求前执行 `markSent`，只有第一次返回 true 才可发送；请求是否实际到达供应商不确定时保守占用预留。
- 实际用量超过预留时如实入账并停止新增付费调用，不截断实际费用；待核实费用也阻止新增付费调用，直到有真实依据完成结算。

上传覆盖、历史选版、重新定位、BV 绑定、删除媒体，以及新增或重试预处理/试映任务均检查活动制作运行。媒体任务创建与重试增加相同的任务锁顺序，避免可重复读快照漏掉另一事务刚提交的任务。只读历史不受限制。

## 对外接口

统一前缀 `/api/creator/tasks/{taskId}/creation`，归属沿用当前个人工作台的 default，不引入账号体系。媒体功能开关关闭时不开放控制器。

| 方法与路径 | 入参 | 行为 |
| --- | --- | --- |
| POST 根路径 | `Idempotency-Key`，`expectedWorkspaceRevision`，`budgetLimitCny` | 显式初始化预算；无工作区时修订号为 -1；重放相同请求返回已有状态 |
| GET `/runtime` | 无 | 返回初始化状态、修订号、预算分类和活动运行摘要；no-store |
| PATCH `/budget` | `expectedWorkspaceRevision`，`budgetLimitCny` | 有限正金额，最多 12 位整数和 6 位小数；不能降到已占用费用以下 |
| GET `/runs/{runId}` | 精确运行 ID | 归属校验后返回摘要；不返回输入正文和租约；no-store |
| POST `/runs/{runId}:cancel` | 无 | 指定运行的单调取消操作，重复调用不重复推进工作区 |

请求体沿用 Jakarta Validation。ID 有界校验；无归属对象返回不存在，业务状态冲突返回 409。执行器和真实确认入口接入前，**没有对外启动、重试或授权接口**。快照固定返回 `executionAvailable=false`、`budgetScope=CREATION_RUNTIME_ONLY`，不能提示用户已经可以自动制作。
