# S3b：真实产物保存与独立版本注册

本步延续 S3a，解决后端拿到渲染产物后怎样进入现有视频版本库。输入是固定工程、内部取得的整片授权和活租约；输出是已保存、可恢复的独立 UPLOADED 版本。默认仍不开放公开启动接口。

设计沿用已确认总方案：使用 ObjectStorageService 上传及回读校验；上传前记录文件清单与执行身份；保存版本时重查取消、租约代数、授权、当前选版、真实发布确认和本运行的制作计划。数据库统一 SQL 增加尝试清单表，不引入新存储客户端或迁移框架。

整片内部受理与准备授权分开，冻结发布会话、方案、AI_GENERATION 制作计划、基准版本、故事板与工程内容摘要。工程内容摘要不包含 runId、attemptId、inputHash，以免运行尚未创建时出现循环；实际渲染清单仍使用完整 RenderInputV1 摘要。

上传完成后以短事务原子写入成片、SYSTEM_RENDER 上下文和当前版本指针。新版本必须走原探测与试映路径，不能直接写 READY_FOR_REVIEW 或让 FULL 提前 COMPLETED。已有成片的 planning_skipped 不能放行系统生成版本。删除媒体时覆盖已登记的字幕、封面和清单对象。

本步不实现持久化 worker、自动蓝图的产物驱动步骤或付费完整试映；内部受理仅供后续实际确认流程接入，不代表页面已有自动出片能力。测试覆盖真实隔离 MySQL、存储往返、幂等、回滚、取消/失租/接管、旧版保留和完整媒体删除；替身与真实媒体证据分别记录。

实际结果：290 项回归加 3 项摘要边界补测通过，含 69 项真实隔离 MySQL。84 秒中文配音工程重新实际渲染，经现有 S3 客户端在一次性 RustFS 私有存储上完成上传、回读、登记、原 FFprobe 和删除。命令和发现的问题见 [验证记录](../error/系统成片保存S3b验证记录.md)，接口边界见 [接入说明](../reference/系统成片保存与版本登记说明.md)。未部署，未调用真实阿里云 OSS 或付费模型。
