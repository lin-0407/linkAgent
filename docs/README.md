S4-3c 增加时间线调整的显式采纳：作者只能选择当前 `timing` 报告里真实存在的 `EXTEND_SCENE` / `SHORTEN_SCENE` 及其原值，服务端同步视频截取区间、重算整片时间线、按新总时长延展或收缩背景音乐区间，并同时新建简报版本（新目标时长）与故事板版本（父版本保留）。旧简报/旧工程原文、素材快照和字幕来源不变；超出素材实际时长的延长被拒绝，不做循环或变速。见[实现说明](develop/视频自动制作-S4-3c时间线调整采纳与重排.md)、[接口说明](reference/时间线调整采纳接口说明.md)、[验证记录](error/视频时间线S4-3c验证记录.md)。

S4-3d 补齐环境声：简报新增可选 `ambience`，作为与背景音乐并列的第二路长音频，拥有独立音量与淡入淡出、固定不随对白压低、必须覆盖全片且不能与背景音乐共用素材。渲染器把区间读取抽成 `AudioBed`，背景音乐保留可选压低，环境声始终稳定；`timeline:apply` 采纳时长提案时同步延展两路区间。见[实现说明](develop/视频自动制作-S4-3d环境声独立混音.md)、[接口说明](reference/环境声混音接口说明.md)、[验证记录](error/视频环境声S4-3d验证记录.md)。页面入口仍未提供。

S4-4 接入可配置 AI 视频生成：部署者按兼容异步协议填写服务地址、模型与密钥，能力接口只返回脱敏状态；`scope=SELECTED` 只生成 AI 镜头，`scope=ALL` 是全片切换提案；预算授权后异步提交、保存任务标识、重启续查，结果下载后经真实解码规范化并登记为私有 READY `VIDEO_CLIP`；提示词摘要绑定片段，改词或改标题后旧片段失效；片段短于场景只返回缩短提案。见[实现说明](develop/视频自动制作-S4-4可配置AI视频生成.md)、[接口说明](reference/AI视频生成接口说明.md)、[验证记录](error/视频生成S4-4验证记录.md)。真实视频供应商、真实账单与页面仍未验收。

## 项目定位（必读）

LinkAgent 是开源、个人自托管的 B 站创作者工作台。默认一套部署由一位创作者使用；公网地址仅用于作品演示和联调，不是公开运营的多用户 SaaS。

作者已明确后续主要服务不会制作视频的新手和希望减少重复工作的小 UP，逐步增加视频自动制作与修改能力。首发范围、现有能力边界和实施验收以 [详细方案](develop/面向新手与小UP的视频自动制作与修改方案.md) 为设计基线；专业制作团队并非当前目标用户。

后续出现 userId 或数据隔离需求时，目标只是避免不同本地或演示场景的数据混淆。除非作者明确改变项目定位，文档和实现都不应擅自扩展为注册登录、租户、网关、RBAC、用户配额或企业级安全体系。
