## 项目定位（必读）

LinkAgent 是开源、个人自托管的 B 站创作者工作台。默认一套部署由一位创作者使用；公网地址仅用于作品演示和联调，不是公开运营的多用户 SaaS。

作者已明确后续主要服务不会制作视频的新手和希望减少重复工作的小 UP，逐步增加视频自动制作与修改能力。首发范围、现有能力边界和实施验收以 [详细方案](develop/面向新手与小UP的视频自动制作与修改方案.md) 为设计基线；专业制作团队并非当前目标用户。

后续出现 userId 或数据隔离需求时，目标只是避免不同本地或演示场景的数据混淆。除非作者明确改变项目定位，文档和实现都不应擅自扩展为注册登录、租户、网关、RBAC、用户配额或企业级安全体系。
