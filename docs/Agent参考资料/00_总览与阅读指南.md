# 《Java + Spring AI Agent 开发说明书》— 速查索引

> **技术栈基线**：Java 17+ / Spring Boot 3.x / Spring AI 1.1.4
> API 均来自 Spring AI 官方文档 (docs.spring.io/spring-ai/reference)、OpenAI、Anthropic 官方接口。工程取舍额外标注 **[工程建议]**。

## 章节地图

| 章 | 主题 | 要点 |
|---|---|---|
| 1 | 最简 Agent 模型 | 裸 HTTP → 手写 ReAct 循环；Agent 本质是 while 循环 |
| 2 | Spring AI 入门 | ChatClient、Prompt、Message；用 Spring AI 重写第 1 章 |
| 3 | 工具调用 | `@Tool` 注解、ToolCallback、自动多轮调用 |
| 4 | 记忆与多轮对话 | ChatMemory、MessageWindowChatMemory、Advisor |
| 5 | RAG 检索增强 | VectorStore、QuestionAnswerAdvisor、文档切分 |
| 6 | 规划 | ReAct vs Plan-and-Execute；自己实现 Planner |
| 7 | 多 Agent 协作 | Supervisor 模式、消息总线、任务路由 |
| 8 | 可观测性与成本 | Spring AI Observation、Token 预算、限流 |
| 9 | 生产级架构 | SSE 流式输出、异步、持久化、幂等、降级 |
| 10 | 完整案例 | 客服工单 Agent，前 9 章拼成真实项目 |
