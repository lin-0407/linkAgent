# 固定工程真实渲染 S2 验证记录

日期：2026-10-20。范围是固定工程、离线媒体与真实进程边界，无供应商付费请求，不修改主业务服务或数据库。

## 环境与准备

独立 `renderer/Dockerfile` 使用 Python 3.12 slim-bookworm、FFmpeg/FFprobe 和系统 Noto CJK 字体；Python 依赖固定为 Pillow 11.3.0、NumPy 2.2.6、fonttools 4.59.0。字体由系统包连同许可证提供，不打包作者的 Windows 字体。

首次构建默认 Debian 源响应缓慢，元数据约两分钟、逐包响应持续数秒。核对构建客户端 PID 后只停止了本次构建；以镜像参数重新构建，未修改作者已有容器、全局软件源或业务配置。镜像探测还确认旧媒体运行镜像有 FFmpeg/FFprobe、没有 Pillow 与中文字体，不能把旧镜像可启动当成 renderer 环境可用。

Windows PowerShell 5.1 读取含中文的无 BOM 脚本会解析失败；离线语音脚本改为 UTF-8 BOM。样例音频复用核对文本、离线声音和语速元数据，避免修改测试脚本后沿用旧内容的声音。

实际构建命令：

```powershell
docker build --build-arg APT_DEBIAN_MIRROR=http://mirrors.ustc.edu.cn --label linkagent.scope=renderer-s2 -t linkagent-renderer:s2-20261020 renderer
```

## 自动测试

```powershell
docker run --rm --network none --memory 512m --cpus 2 --pids-limit 64 --read-only --tmpfs /tmp:rw,size=1g --entrypoint python linkagent-renderer:s2-20261020 -m unittest discover -s tests -v
```

最终源码镜像实际执行 **30 项测试全部通过**，用时 13.781 秒。验证包含严格输入、重复 JSON 字段、路径穿越、Windows 绝对路径、越界链接、密钥文件、实际素材与摘要、实测音频和字幕范围、字体缺字、文字溢出、亮背景拒绝、旧输出覆盖、真实 H.264/AAC 编解码与完整清单，以及真实编码失败、超时、取消、socket 和密钥读取拒绝。720p/24fps 和 1080p/25fps 均完成真实编码与整片解码。协议测试使用可控测试音，不据此声称真实语音或产品供应商链路通过。

首轮真实测试发现两处边界，修正后重建镜像复跑：

- 输出端 `-frames:v` 会使 FFmpeg 在视频达到指定帧数时提前结束复用，截短尾部音轨。最终按受控帧循环和输入 EOF 结束视频流，让完整 PCM 音轨独立读到 EOF；FFprobe 继续严格核对实际帧数和音视频时长，没有放宽容差绕过错误。
- 示例分句把单独的句号切成无声音频，导致零时长 cue 被契约拒绝。纯标点合回前一句后重新合成相应局部音频，并新增零时长字幕拒绝回归，不伪造时长或跳过验证。

## 跨主题真实媒体

准备命令使用 bundled Python 执行 `renderer/examples/build_examples.py`，运行本机 `synthesize_local.ps1` 后再 `--finish`。旁白来源 Microsoft Huihui Desktop、Windows System.Speech 离线语音，rate=1，paidCalls=0。逐句保存 WAV 与语音元数据，再按真实采样数拼接，字幕文字和分句音频一一对应，不按字数猜时间。

样例为休息提醒（约 84.167 秒、6 场景）、HTTP 请求（约 38.958 秒、3 场景）、厨房整理（约 38.667 秒、3 场景）；不同内容共用同一结构和 renderer 源码，不替换成同一故事的不同标题。图片由本地固定示例脚本原创绘制，声音与图片保存在忽略的 `export/renderer-s2-20261020`，不提交二进制素材或本机环境文件。

渲染命令形态：

```powershell
docker run --rm --network none --memory 512m --cpus 2 --pids-limit 64 --read-only --tmpfs /tmp:rw,size=64m --mount type=bind,source=E:/linkAgent/linkAgent/export/renderer-s2-20261020,target=/work linkagent-renderer:s2-20261020 render --input /work/rest/input.json --work-root /work --output-dir /work/rest/attempt-2 --timeout-seconds 600
```

最终三个容器均退出 0。媒体为 1280×720、24fps、H.264/yuv420p、48kHz 双声道 AAC；每个成功清单均完成整片解码检查，削波采样为 0：

| 工程 | 实际时长 | 实际帧数 | MP4 大小 | 本次渲染与检查耗时 | 解码峰值 |
| --- | ---: | ---: | ---: | ---: | ---: |
| rest | 84.167s | 2020 | 1,814,049 bytes | 44.514s | 0.687317 |
| http | 38.958s | 935 | 871,538 bytes | 27.423s | 0.706024 |
| kitchen | 38.667s | 928 | 845,594 bytes | 25.021s | 0.665222 |

以上为各自 2 CPU/512MiB 容器并行执行的单次结果，不据此保证其他机器的速度。全部产物另在宿主机逐一复核大小和 SHA-256，与成功清单一致。每个成功目录保留 MP4、SRT、封面、首中尾 PNG、render.log、manifest.json；内部 WAV 与 partial 文件已清理。

已查看三个成片的九张实际抽帧，标题、正文和字幕未见裁切；全图、图文并排和两项对比构图有差异，字幕底板未遮住正文。抽帧汇总保留为 `export/renderer-s2-20261020/validation-contact-sheet.png`，机器核对摘要为同目录 `validation-summary.json`。这属于画面布局和确定性媒体检查，没有独立 ASR 准确率或真人观看评价结论。
