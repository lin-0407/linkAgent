## 重点行为

- 初始化不由 GET 触发；幂等重放不改变修订号，旧 V1 当前指针保留。
- 授权绑定不可变输入；TEXT/PREPARE 不接受整片启动；原子受理失败会回滚新授权和修订号。
- 两个启动并发只有一个成功；媒体任务与制作启动共用任务锁；运行表唯一键进一步限制唯一活动任务。
- 费用预留并发不能透支；任务预算和授权余额分别校验，上调任务预算不放大授权，重试不清零历史消耗。
- 排队取消立即释放；执行中取消仍占用位置；等待依赖释放租约、保留位置，可经领取者确认取消。
- 接管增加代数；旧心跳、旧发送和旧完成被拒绝。未发送费用释放，已发送费用变 UNKNOWN。
- 取消后的真实费用可迟到结算，相同结算不重复累计；未知费用保留金额；超过预留的真实费用如实记录并阻断后续付费。
- 活动运行拒绝上传覆盖、选版、重新定位、BV 绑定、删除媒体和人工预处理/试映新增。
- HTTP 参数缺失、负修订号、零任务预算、超范围和超精度金额被拒绝；查询 no-store；未提供公共启动接口。
- 统一建表脚本对已有表重放成功；不以纯 Mapper mock 代替数据库事务与 SQL 验收。

## 自审修正

审查补充了人工媒体任务与制作运行的共同任务锁：如果先产生可重复读快照、再等待版本锁，后续普通查询可能看不到另一事务刚提交的活动工作。启动、媒体创建和重试现在先取得任务锁，再查询状态；制作启动也在首次快照读前锁版本。该风险通过真实并发测试验证。

输入解析增加重复键和尾随正文拒绝，避免相同 JSON 前缀被误认为同一输入；金额整数位计算使用 long，避免巨大指数的整型溢出。

## 结论边界与清理

数据库与应用编排行为使用真实 MySQL；对象存储、供应商和既有试映结果使用测试替身或隔离构造。没有自动渲染、真实 OSS/模型/TTS/ASR/B 站或浏览器验收结论，没有启动自动执行器，没有部署。已有人工链路费用未全部归并，不宣称严格任务全局预算通过。

测试 runner 和带 `linkagent.scope=creation-s1` 的本轮 MySQL 容器在结束时核对清理；原有容器和端口不操作。没有需要作者补跑的后端命令。
