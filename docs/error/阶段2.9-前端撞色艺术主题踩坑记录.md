# 阶段 2.9 - 前端撞色艺术主题踩坑记录

## 1. 样式长期放在 App.vue 会限制后续扩展

问题：

之前全局样式集中在 `App.vue`，首页可以跑通，但后续新增页面时很容易复制样式，导致主题分裂。

处理：

将全局视觉语言抽离到 `src/styles/theme.css`，并在 `main.ts` 中统一引入。

## 2. 撞色不能只靠红粉两种颜色

问题：

如果页面只使用石榴红和雾粉桃，会变成单一色相堆叠，缺少工程控制台的稳定感。

处理：

加入墨色作为结构锚点，加入青绿和金色作为状态与焦点色，让视觉更有层次。

## 3. 艺术感不能牺牲交互可读性

问题：

强视觉页面容易把内容阅读和按钮状态压下去，尤其是会话列表、Markdown、代码块和 ReAct 时间线。

处理：

保留明确的内容底色、滚动区域、焦点样式和移动端断点，并通过构建验证确保类型和打包没有被破坏。
