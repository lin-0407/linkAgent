# RAG 主题优先检索前端接入踩坑记录

## 1. Vue 事件会把点击事件传给函数

**问题**：`@click="submitSearch"` 会把浏览器事件对象传入函数。如果函数第一个参数是 `page`，就会把事件对象当成页码。

**处理**：改成 `@click="submitSearch()"` 和 `@keyup.enter="submitSearch()"`。

**原因**：主题检索的 `page` 必须是数字，不能让模板隐式传参污染请求体。

## 2. 卡片按钮里不要嵌套段落标签

**问题**：把整张视频卡片做成 `<button>` 后，里面如果继续放 `<p>`，浏览器可能自动修正 DOM，导致布局和点击区域异常。

**处理**：检索卡片内部统一用 `span` 展示摘要、标签、主题命中。

**原因**：交互元素内部结构要稳定，尤其是卡片整体可点击时。

## 3. 不要把上下文直接显示成用户消息

**问题**：如果把视频、主题和评论弹幕全部塞进输入框，聊天窗口会被大段材料刷屏。

**处理**：`useAgentChat.sendMessage` 支持 `displayMessage` 和 `outboundMessage`。前端只显示用户问题，实际请求附带上下文。

**原因**：用户需要看清自己的问题和 AI 回答，材料应该作为隐式上下文进入请求。

## 4. AI 浮窗不能只挂在创作工作台页

**问题**：原来 AI 浮窗只在创作工作台页面挂载。案例库页点击卡片时，如果浮窗不存在，就接不到视频上下文事件。

**处理**：把 `AgentFloatingWindow` 提升为全局常驻组件。

**原因**：案例库本身也需要 AI 交互台，默认收起入口即可，不会遮挡页面。
