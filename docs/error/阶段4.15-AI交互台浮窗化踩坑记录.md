# 阶段 4.15 - AI 交互台浮窗化踩坑记录

## 1. 不能直接把完整 AgentConsole 塞进浮窗

问题：`AgentConsole.vue` 是页面级组件，包含侧边栏、顶部统计、主视觉、全屏按钮等布局。如果直接复用，会导致浮窗内容过重，且小窗口里出现大量不适合浮窗的页面元素。

处理：新增 `AgentFloatingWindow.vue`，只复用 `useAgentChat`、`MessageBubble`、`ChatComposer` 和 `ErrorNotice`。

## 2. 浮窗不应和 Agent 控制台同时挂载

问题：浮窗和原 Agent 控制台都会调用 `useAgentChat`，而 `useAgentChat` 会读取本地保存的会话 ID 并加载会话列表。如果两个入口同时挂载，会产生重复加载和状态理解成本。

处理：浮窗只在创作工作台模式下挂载。切到原 Agent 控制台页面时，浮窗不渲染。

## 3. 尺寸限制不能只写 CSS

问题：只写 `max-width/max-height` 可以限制视觉尺寸，但拖动和缩放逻辑仍可能把窗口位置计算到视口外。

处理：在脚本层统一计算 `width/height/left/top`，每次拖动和缩放都调用同一个边界约束函数。

## 4. 本地 Git 安全目录提示

问题：在 Codex 沙箱用户下执行 `git status` 时，Git 提示仓库所有者和当前用户不同。

处理：本次只用临时参数读取状态：

```bash
git -c safe.directory=E:/linkAgent/linkAgent -C E:\linkAgent\linkAgent status --short
```

没有写入全局 Git 配置。
