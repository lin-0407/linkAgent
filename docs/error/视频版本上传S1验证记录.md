# 视频版本上传 S1 验证问题

## 2026-10-19：原已绑定 BV 单元测试未区分加锁与重新体检

第一轮运行 57 项测试，8 项真实 MySQL 集成测试通过；`CreatorBilibiliServiceTest.shouldNotOverwriteBoundBinding` 失败。旧断言要求 `CreatorMediaWorkflowGateService` 零交互，新增版本并发保护则在绑定事务第一次读取前调用 `lockForVideoBinding`。

没有删除这条测试或取消原有 BV 幂等保护。断言调整为：必须取得任务锁，不允许其他媒体服务调用；原绑定 BV 仍保持不变，不执行 `ensureReadyForPostPublish`，不更新绑定内容。再运行同组回归，并补充旧 `published_flag` 的真实数据库测试。

Testcontainers 在一次性 Maven 容器中通过 Docker socket 创建独立 MySQL，使用 `TESTCONTAINERS_HOST_OVERRIDE=host.docker.internal` 访问其动态映射端口。运行中禁用 Ryuk，因此结束后除 JUnit 容器生命周期清理外，还检查本轮标签 `linkagent.scope=creation-s1`，不清理作者的评测实例。

最终结果和准确命令以 [S1a-1 实现说明](../develop/视频自动制作-S1a-1独立版本上传实现说明.md) 为准。

## 2026-10-19：重新定位会批量破坏历史；本地恢复可能把旧版显示成当前版

业务兼容复查发现：原重新定位重置全部成片探测信息、逻辑删除全部预处理/试映；多版本下会失去已完成历史。另有事务外准备的旧上传请求可能跨越重新定位，以及前端只按旧上传会话恢复造成当前版展示错误的问题。

已改为保留已完成历史、清空当前指针并收敛活动任务，补任务锁内发布事实与工作区修订号检查；恢复已完成上传时先核对后端当前版本。后端 64 项测试通过，包含 14 项真实隔离 MySQL；前端只做静态核对，浏览器未验收。具体差异、实际命令和未验证部分见 [修复说明](../develop/视频自动制作-S1重新定位历史隔离修复说明.md)。

## 2026-10-19：精确版本绑定的映射与真实试映测试数据

本轮首轮编译发现新增绑定响应字段被误加到相邻账号响应转换中，已改到 `toBindingResponse`；账号接口保持原字段。后续 74 项回归中，单元测试通过，真实 MySQL 新增绑定场景有 5 项返回“请先完成试映”。排查确认测试只构造 COMPLETED 报告，漏掉成片 `current_review_id` 和 `ANALYZE_VIDEO` 步骤，真实 `findCurrentByVersion` 不会把这种报告当成完整试映。

补齐的是新场景测试数据，没有放松生产查询或移除门禁断言。版本绑定测试需同时验证真实指针、步骤、处理任务、归属和事务，不能只靠 mock 的 COMPLETED 字符串证明完整链路可用。最终结果与命令见 [精确发布版本绑定说明](../develop/视频自动制作-S1精确发布版本绑定.md)。

74 项回归通过后的删除兼容自审发现，新加的全局 `mediaDeletedAt` 阻断会破坏原“删除媒体但保留历史报告、允许继续反馈复盘”的规则。该新增判断已撤掉，增加使用真实删除服务与 MySQL 的回归；对象存储用替身，仅验证删除编排，不宣称真实 OSS 删除通过。媒体记录缺失与存储对象删除需要分别处理。

最终重跑同组 7 个测试类：75 项通过，0 失败、0 错误、0 跳过，包含 21 项真实 MySQL 集成测试。新增删除兼容场景也已通过。

## 2026-10-19：版本上下文与选版闭环自审

自审确认旧媒体身份已有保护，但最新方案仍能阻断旧版，正式标题/简介也随缓存变化。本轮增加不可变上传上下文和首次核验时的公开资料冻结，随后接入历史选版、前端入口及反馈分析的正式资料读取。

真实 MySQL 首轮 132 项回归有两项测试数据错误：新蓝图错误复用版本号 1，以及 Mockito 的旧抛错桩在重新 `when(...)` 时先抛出。分别改为新版本号 2 和 `doReturn(...)` 后验证通过；未通过放松唯一键或业务异常来绕过。

后续自审修复正式发布事实被负向同步状态覆盖的问题：确切版本在首次 BOUND 保存永久发布标记，后续异常不能允许重新定位、换 BV 或让门禁回退编辑页当前版。冻结快照的 JOIN 写入会读取缓存行，因此同步事务必须先锁任务/绑定，再写缓存，保持与显式绑定一致。已保存的冻结资料不被后续冲突缓存指标污染。

版本上下文无法可靠还原的旧记录保持未知；只为新上传捕获真实依据，不按当前计划自动回填旧版。补列脚本在独立旧表上验证重复执行，作者现有库未改动。详细结果与命令见 [闭环说明](../develop/视频自动制作-S1版本上下文与历史选版闭环.md)。

最终源码同组 13 个测试类回归：139 项通过，包含 34 项真实 MySQL；0 失败、0 错误、0 跳过。前端入口未做浏览器验收，未部署。
