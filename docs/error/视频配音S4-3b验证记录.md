## 本轮发现并修复的问题

1. **任务行映射错位**：`SELECT *` 映射到 `Job` record 时，`storyboard_result_id` 读到了其他列的值，准备结果被误判成摘要。三个查询改为显式列名。

2. **存储桶未配置时写出不可用素材**：生成音频落库后才被编译器判为 `ASSET_RENDER_LIMIT`。现在缺少桶配置直接失败 `VOICE_STORAGE_NOT_CONFIGURED`，测试环境显式配置独立桶。

3. **供应商身份为空**：场景行在排队时 provider/model/voice 为空，合成开始只更新数据库、没有刷新内存对象，素材元数据记录了空值。现在合成后重新读回场景再写音频事实，并补充格式与采样率。

4. **收尾异常把运行留在占用状态**：保存新版本或完成运行抛异常时只写日志，运行保持 `RUNNING` 直到租约过期。现在收尾失败显式结束运行，避免反复领取同一失败结果。

5. **取消后场景仍显示失败**：取消期间抛出的异常会把场景写成 `FAILED`。现在取消路径不再写失败，由运行收尾统一标记为取消；失败运行的遗留行标记为 `VOICE_RUN_FAILED`。

6. **过期任务行直接抛 409**：扫描结果可能刚被取消，`process` 直接 `claim` 会抛“运行已不再是当前活动运行”。现在把过期视为跳过。

以下由独立子 agent 只读审查后修复：

7. **中断在合成中的场景会让后续场景先付费再失败**：接管时未检查 `SYNTHESIZING`。现在开始执行前先核对：有发送事实记 `UNKNOWN` 并结束运行，没有发送事实才回到排队重试。

8. **接管后未发送的预留无法重新占用**：`reopen` 要求同一租约代，而接管已经换代数。改为 `rearm`：只在 `sent_at` 为空时按当前执行代重新占用同一调用标识。

9. **文稿 `strip()` 与编译器摘要不一致**：服务端去掉首尾空白后计算摘要，编译器使用原文，带空白的文稿会永远 `TTS_TEXT_MISMATCH`。现在原样保存文稿与摘要。

10. **供应商 4xx 被当成结果不明**：明确的 4xx 拒绝没有生成音频，却会留下 `UNKNOWN` 并暂停任务后续付费调用。现在区分“明确拒绝”（按 0 结算、失败码 `VOICE_TTS_REJECTED`）与“结果不明”（`UNKNOWN`）。

11. **短签在发送标记之后才生成**：ASR 地址签名失败会留下已发送但未提交的未知费用。现在先本地签名，再预留和发送。

12. **估算逐项取整与逐次结算不一致**：批量换算可能比逐次结算少 1e-6，导致受理后首次预留失败。现在每次调用的人民币金额分别取整后求和。

13. **结算使用当前部署价格**：恢复或改配置后会用新单价结算旧调用。现在从预留时的价格快照读取单价与汇率。

14. **场景毫秒与量化帧长比较存在边界误判**：音频按毫秒、场景按帧量化，边界上可能差一帧。现在先量化场景帧长再比较。

15. **`beginSynthesisWith` 缺少租约围栏**：旧执行可能把场景从排队推进。现在同 SQL 核对活动运行、租约所有者和代数。

16. **工程不可渲染只写日志**：运行失败码统一成准备失败。现在把具体原因保留为运行失败码（如 `VOICE_BOARD_NOT_RENDERABLE`）。
