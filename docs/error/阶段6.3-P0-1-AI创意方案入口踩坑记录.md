# 阶段 6.3 P0-1 - AI 创意方案入口踩坑记录

## 1. 范围控制

本轮只实现 P0-1：用户想法输入、三张创意卡片生成、选择确认。

没有实现 BV 绑定、UID 绑定、视频分析页和开销统计入口。原因是这些属于后续 P0-3 到 P0-5，如果混在本轮会扩大表结构和页面状态范围。

## 2. 兼容旧任务体系

问题：

现有发布前优化只读取 `creator_task` 和 `creator_material`，如果交互式创作完全另起一套数据结构，第二阶段会拿不到上下文。

处理：

创建交互式任务时仍创建标准 `creator_task`。用户确认创意卡片后，把原始想法和已选创意方向回写到 `creator_material.MANUSCRIPT`。

影响：

后续发布前优化可以继续复用旧接口，但 P0-2 需要把“固定表单”展示方式改成 AI 主动追问。

## 3. LLM JSON 漂移

问题：

模型可能返回非 JSON、字段缺失或 options 数量不足。

处理：

后端先尝试解析 JSON；解析失败时记录 `parseStatus=RAW_ONLY`，并生成三张兜底卡片保证流程不中断。

影响：

兜底结果能让用户继续操作，但质量不等同于真实模型输出。后续应补充创意卡片质量评测。
