# 前端 P0 用户化重构阶段问题整理

## 1. 历史项目自动抢占首屏

问题：创作台刷新任务列表后会默认选择第一条历史任务，导致普通用户进来后看不到“开始优化一条视频 / 继续上次复盘”的首屏入口。

处理：`resolveRefreshTargetTask` 只恢复当前选中项目或本地明确记录过的项目，不再默认选择第一条任务。

## 2. 工程信息散落在普通路径

问题：工作流消息、API 开销、评测样例、检索策略、证据索引等信息原本直接出现在普通页面，用户会被迫理解工程概念。

处理：新增前端本地开发者模式开关，普通模式隐藏这些信息，开发者模式继续保留。

## 3. AI 浮窗仍会展示推理轨迹

问题：即使隐藏执行模式按钮，消息气泡组件仍会展示执行模式、步骤轨迹和停止原因。

处理：`MessageBubble` 增加 `showDiagnostics` 参数，AI 浮窗普通模式传入 `false`，开发者模式传入 `true`。

## 4. 反馈导入结果可能只剩工程输出

问题：如果反馈采集成功但仪表盘接口暂时失败，普通模式隐藏脚本输出后弹窗可能没有可读内容。

处理：增加普通用户可读的“读取完成”兜底提示，只展示评论和弹幕数量。

## 5. 验证限制

本项目约定开发者不得执行前端构建、类型检查、运行或启动命令。本轮只做静态检查，最终需要作者执行验证命令并反馈结果。
