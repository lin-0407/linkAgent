## 实际行为证据

- 真实 MySQL 使用统一 `init.sql`，实际 MyBatis 与事务代理验证简报/故事板不可变版本、幂等键竞争、工作区修订冲突、来源冻结、素材任务/归属与 READY 校验，以及旧版本引用查询。
- 准备授权、运行和任务记录处于同一事务；无结算时保存故事板/完成运行整体回滚。取消或旧租约不能保存候选，候选完成不切成片版本。
- 估算只读，不创建授权、运行、任务或费用，不推动工作区版本；低于估算的授权拒绝。模型上下文与估算响应不带 bucket/objectKey，私有定位只在后端冻结。
- 实际 Worker 配合真实账本验证按原价格和汇率结算、坏 JSON 仍保留已发生费用、缺失单侧 token 记 UNKNOWN 并阻止下一次付费发送、旧 SENT 恢复不重发。取消时模型忽略中断的受控场景，先取消/UNKNOWN，迟到用量再结算，不能保存候选。
- 本地 HTTP 协议替身观察真实请求次数、报文与响应解析：429/503 各只发送一次，工具调用不能触发续调，自定义路径/头保留，默认模型选项不会覆盖输出上限，缺失用量不补零。这里没有真实供应商。
- 同一编译器、素材落盘服务和已有 Python/FFmpeg 渲染器实际处理阅读、烹饪、旅行三个主题，每个工程 120 帧/4 秒，并输出字幕和不同内容摘要；另一个 1 秒纯文字静音工程验证生成的受控占位 PNG 和实际输出静音，文件仍保留 AAC 音轨。这些测试从受控 Candidate 开始，素材来自夹具对象拷贝，没有经过模型/公开 API/OSS 完整链路；混合声音技术用例也不代表简报的声音选择规则被绕过。
- 控制器用 MockMvc 检查 Jakarta Validation、202/no-store、估算不要求付费授权、路径素材和空场景拒绝，以及未开放公开 FULL。桥接分支单测验证 PREPARE 不能升级 FULL、丢响应/暂空/查询失败保留文件、明确另一尝试占用才删除；这些边界单测不等于真实整片部署验收。

## 本轮发现并修复的问题

### 容器增量构建复用了旧 class

快照 tar 保留宿主源文件修改时间，容器生成的 class 时间更晚；替换源码后 Maven 增量检测仍可能判断无需编译。仅核对源码摘要和 Maven 退出码不足以发现该问题。本轮同时核对测试 XML 的方法与数量，发现新增桥接用例未执行，改为 `clean test` 删除本轮独立容器中的 `target` 后完整重编译，最终结果以重编译后的报告为准。

### 关闭模型重试仍会重发 POST

单独将 Spring Retry 设为一次，未阻止 Apache HTTP 默认对 429/503 的传输重试。真实本地 HTTP 计数复现后，故事板调用克隆部署 OpenAiApi 和 Boot RestClient 配置，单独采用 JDK 传输，保留入口、密钥和定制头，同时禁用框架重试与工具续调。全局聊天客户端不变。失败或 SENT 恢复不会自动再次请求；发送结果不明保留 UNKNOWN。

### 极低费用授权仍能发固定输出上限

原实现直接把任意 `maxAdditionalCostCny` 当预留，却始终请求最多 4096 输出 token。修复为用实际提示词/结构 Schema/上下文 UTF-8 字节数加消息余量估算输入，再和 4096 输出及配置单价/汇率一起向上取六位小数，冻结 `reservationCny`。受理低授权前即拒绝，Worker 发送前再次核对且按冻结估算预留。

这是保守的**配置费用估算**，不是任意供应商分词器或真实账单的绝对上限。供应商实际用量仍按返回值结算，异常超支遵循原账本规则；供应商价格和真实账单尚未核实。

### 工程登记丢响应时误删输入

原异常收尾无条件删除本次源工程；事务已成功或迟到提交时，会造成后台任务指向不存在的文件。现在发送登记之前的本地冻结失败可清理；登记发出后，同尝试已登记则幂等返回，查询失败或暂未查到都保留文件，只有明确另一个尝试已占据运行才删除本次文件。状态不明的保留目录后续仍需 S7 统一资源回收，不在这里假定事务失败。
