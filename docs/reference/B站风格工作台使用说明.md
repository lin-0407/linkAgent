# B 站风格工作台

打开系统后直接进入创作台，原展示首页已移除。

- 桌面左侧可以访问创作台、参考案例、项目列表、视频分析、记忆管理和使用日志。
- 手机上点击顶栏的页面菜单切换页面，使用指南也放在菜单里。
- 在创作台写下想法，选择视频类型，再提交；资料可以稍后补充。方向对齐后，由你决定何时生成发布方案。
- 最近创作只显示真实历史任务。没有任务时直接开始第一条创作，不会出现示例项目。
- 进入已有任务后，桌面顶部展示创作步骤，手机显示当前进度；未完成前置步骤的入口继续保持禁用。
- 参考案例保留真实封面、分区互动分和库内同分区排名，分数与排名的计算口径没有改变。
- 参考案例仍可筛选、查看详情、自动采集和导入；记忆、日志、设置继续使用现有功能。

参考案例的展示数量会随窗口调整：宽屏多列，窄屏减少列数，手机为单列；每页取完整的 2～4 行，手机至少 3 行。例如 1440 × 900 的窗口每页 12 条，1280 × 720 每页 6 条。窗口高度也会影响行数，不再固定每页 8 条。缩放后继续显示原先浏览位置附近的案例，最后一页只显示真实剩余内容。列表标题会显示当前每页数量，仍可使用原有筛选和分页按钮。

更新后刷新 `http://localhost:8088/knowledge` 即可；已打开的旧标签页可以按 `Ctrl+F5` 重新加载。实现和检查记录见 [参考案例自适应分页](../develop/参考案例自适应分页.md)。
