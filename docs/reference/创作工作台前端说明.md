# 创作工作台前端说明

## 功能入口

前端默认进入“创作工作台”，顶部可以切换到“Agent 控制台”。

创作工作台覆盖当前 MVP 的三段后端能力：

1. 创作任务与稿件输入。
2. 发布前优化 Agent。
3. 评论弹幕分析。

## 主要文件

| 文件 | 说明 |
|---|---|
| `src/App.vue` | 顶层模式切换 |
| `src/components/CreatorWorkspace.vue` | 创作工作台页面 |
| `src/components/AgentConsole.vue` | 原 Agent 控制台 |
| `src/api/creator.ts` | 创作者业务 API |
| `src/types/creator.ts` | 创作者业务类型 |
| `src/styles/theme.css` | 工作台样式 |

## 输入与视觉约定

1. 新任务表单、发布前补充项、评论弹幕样例和可编辑指导默认保持为空，避免演示样例混入用户真实材料。
2. 字段说明通过输入框内的短占位提示展示，避免用长文案占据输入区域。
3. 创建任务必须先输入标题草稿、简介草稿、文稿或字幕中的至少一项；保存样例必须先输入评论或弹幕中的至少一项。
4. 工作台沿用 Agent 控制台的红黑纸面基调，B 站蓝/粉只用于流程状态、标签和输入焦点等辅助强调。

## 创作指导编辑

发布前优化区域有“创作指导”按钮，评论弹幕分析区域有“分析指导”按钮。

点击后可以：

1. 修改表达风格、建议侧重点和分析顺序。
2. 输入区域默认为空，需要时可通过“恢复默认指导”快速写入推荐规则。
3. 保存到浏览器 `localStorage`。

保存后，下次点击“生成建议”或“分析反馈”时，前端会把 `customGuidance` 传给后端。

后端系统提示词、角色定义、平台数据边界和 JSON 输出结构不展示给用户，也不允许由前端覆盖。

## API 对应关系

| 前端操作 | 后端接口 |
|---|---|
| 创建任务 | `POST /api/creator/tasks` |
| 读取任务列表 | `GET /api/creator/tasks` |
| 读取任务详情 | `GET /api/creator/tasks/{taskId}` |
| 生成发布前建议 | `POST /api/creator/tasks/{taskId}/pre-publish/analyze` |
| 查询发布前建议 | `GET /api/creator/tasks/{taskId}/pre-publish/suggestions` |
| 保存评论弹幕样例 | `POST /api/creator/tasks/{taskId}/feedback` |
| 查询评论弹幕样例 | `GET /api/creator/tasks/{taskId}/feedback` |
| 分析评论弹幕反馈 | `POST /api/creator/tasks/{taskId}/feedback/analyze` |
| 查询反馈报告 | `GET /api/creator/tasks/{taskId}/feedback/report` |

## 本地运行

前端通过 Vite 代理访问后端：

```text
/api -> http://localhost:8080
```

运行前端：

```bash
cd link-agent-frontend
npm run dev
```

构建检查：

```bash
cd link-agent-frontend
npm run build
```

## 注意事项

1. 后端必须先启动，否则页面会显示请求失败。
2. 发布前优化和反馈分析都会调用 LLM，需要确保后端模型配置可用。
3. 当前页面用于 MVP 联调，不做复杂路由和权限控制。
