# 创作工作台前端说明

## 功能入口

前端默认进入“创作工作台”，顶部可以切换到“Agent 控制台”。

创作工作台当前覆盖 MVP 的三段后端能力：

1. 创作任务与稿件输入。
2. 发布前优化 Agent。
3. 评论弹幕分析。

当前页面是表单式 MVP 基线；阶段 4.4.1 会把发布前优化和评论弹幕分析升级为任务驱动的 Agent 工作流消息页。

## 输入与视觉约定

1. 新任务表单、发布前补充项、评论弹幕样例和可编辑指导默认保持为空，避免演示样例混入用户真实材料。
2. 字段说明通过输入框内的短占位提示展示，避免用长文案占据输入区域。
3. 创建任务必须先输入标题草稿、简介草稿、文稿或字幕中的至少一项；保存样例必须先输入评论或弹幕中的至少一项。
4. 工作台沿用 Agent 控制台的红黑纸面基调，B 站蓝/粉只用于流程状态、标签和输入焦点等辅助强调。

## 创作指导编辑

发布前优化区域有“创作指导”按钮，评论弹幕分析区域有“分析指导”按钮。

点击后可以：

1. 修改表达风格、建议侧重点和分析顺序。
2. 输入区域默认为空，需要时可通过“恢复默认指导”快速写入推荐规则。
3. 保存到浏览器 `localStorage`。

保存后，下次点击“生成建议”或“分析反馈”时，前端会把 `customGuidance` 传给后端。

后端系统提示词、角色定义、平台数据边界和 JSON 输出结构不展示给用户，也不允许由前端覆盖。

## API 对应关系

当前 MVP 接口：

| 前端操作 | 后端接口 |
|---|---|
| 创建任务 | `POST /api/creator/tasks` |
| 读取任务列表 | `GET /api/creator/tasks` |
| 读取任务详情 | `GET /api/creator/tasks/{taskId}` |
| 生成发布前建议 | `POST /api/creator/tasks/{taskId}/pre-publish/analyze` |
| 查询发布前建议 | `GET /api/creator/tasks/{taskId}/pre-publish/suggestions` |
| 保存评论弹幕样例 | `POST /api/creator/tasks/{taskId}/feedback` |
| 查询评论弹幕样例 | `GET /api/creator/tasks/{taskId}/feedback` |
| 分析评论弹幕反馈 | `POST /api/creator/tasks/{taskId}/feedback/analyze` |
| 查询反馈报告 | `GET /api/creator/tasks/{taskId}/feedback/report` |

阶段 4.4.1 规划新增接口：

| 前端操作 | 后端接口 |
|---|---|
| 创建或恢复发布前工作流 | `POST /api/creator/tasks/{taskId}/workflow/pre-publish/start` |
| 订阅工作流事件 | `GET /api/creator/tasks/{taskId}/workflow/sessions/{sessionId}/events` |
| 发送工作流消息 | `POST /api/creator/tasks/{taskId}/workflow/sessions/{sessionId}/messages` |
| 上传补充资料 | `POST /api/creator/tasks/{taskId}/workflow/sessions/{sessionId}/attachments` |
| 执行工作流分析 | `POST /api/creator/tasks/{taskId}/workflow/sessions/{sessionId}/pre-publish/analyze` |
| 确认发布前建议 | `POST /api/creator/tasks/{taskId}/workflow/sessions/{sessionId}/pre-publish/confirm` |
| 导入评论弹幕文件 | `POST /api/creator/tasks/{taskId}/feedback/import` |
| 查询反馈仪表盘 | `GET /api/creator/tasks/{taskId}/feedback/dashboard` |
| 评论弹幕追问 | `POST /api/creator/tasks/{taskId}/feedback/chat` |

## 阶段 4.4.1 前端边界

1. SSE 只是实时展示通道，页面刷新后必须能通过历史消息接口恢复。
2. 上传资料第一版只支持文本类文件，不做图片 OCR、音频转写和视频解析。
3. 评论弹幕第一版只处理用户主动粘贴或脚本导出的样例文件，不在前端暗中自动抓取平台数据。
4. 发布前建议必须由用户确认后才进入正式下一阶段。
5. Agent 控制台继续保留为通用能力入口，创作工作台中的 Agent 消息流只服务当前创作任务。

## 本地运行

前端通过 Vite 代理访问后端：

```text
/api -> http://localhost:8080
```

运行前端：

```bash
cd link-agent-frontend
npm run dev
```

构建检查：

```bash
cd link-agent-frontend
npm run build
```

## 注意事项

1. 后端必须先启动，否则页面会显示请求失败。
2. 发布前优化和反馈分析都会调用 LLM，需要确保后端模型配置可用。
3. 当前页面用于 MVP 联调，不做复杂路由和权限控制。
