# 前端 P0-4 视觉和响应式收口说明

## 功能概述

P0-4 收口的是创作台的前端视觉一致性和移动端可用性。

本轮没有新增后端能力，而是让已有“视频资料、发布方案、观众反馈、复盘报告”四步流程在桌面端和移动端都更稳定。

## 用户侧变化

1. 移动端进入创作台后，会在顶部看到当前步骤、步骤总数和进度条。
2. 移动端步骤导航变成横向可滑动的轻量步骤条，避免左侧栏挤压表单。
3. 按钮触控区域统一不小于 44px，方便手机点击。
4. 长文本结果块和任务项会自动换行，降低横向滚动风险。

## 实现要点

### 当前步骤元信息

`CreatorWorkspace.vue` 增加 `creatorStepMetas`，统一维护普通创作者路径的四个步骤。

`activeCreatorStepIndex` 根据 `activeStep` 推导当前步骤索引。

当 `activeStep` 是开发者辅助入口 `usage` 时，移动端进度条保持在“复盘报告”阶段。

这样做是为了避免普通创作者流程被开发者入口扩成第五步。

### 移动端进度条

`CreatorWorkspace.vue` 在流程栏中增加 `.creator-mobile-progress`。

该结构默认隐藏，只在窄屏断点下显示。

进度条宽度由 CSS 自定义属性 `--creator-progress-percent` 控制。

### 响应式覆盖规则

`theme.css` 末尾增加 P0-4 覆盖规则。

这些规则集中处理：

1. 创作台根容器禁止横向溢出。
2. 常用容器和结果块圆角统一。
3. 常用按钮和步骤按钮触控高度统一。
4. Grid/Flex 子项补充 `min-width: 0`。
5. 480px 下关键网格收为单列。

## 验收口径

建议作者至少检查三档宽度：

| 宽度 | 验收重点 |
|---|---|
| 375px | 无横向滚动；顶部进度条可见；按钮易点击。 |
| 768px | 步骤区不挤压表单；结果块文本不撑破页面。 |
| 1440px | 桌面端左侧流程栏和右侧主内容保持稳定。 |

## 后续建议

1. 如果后续继续拆分 `CreatorWorkspace.vue`，可以把 `creatorStepMetas` 下沉到独立常量文件。
2. 如果需要更精细的移动端体验，可以把步骤条替换成只读进度胶囊，不再展示全部步骤按钮。
3. 如果后续要截图回归，可以补充 375px、768px、1440px 的视觉检查清单。
