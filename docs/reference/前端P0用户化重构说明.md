# 前端 P0 用户化重构说明

## 页面结构

一级导航包括：

- 创作台：当前视频项目的四步主流程。
- 参考案例：查找可借鉴的视频案例。
- 项目列表：继续历史视频项目。
- 设置：普通设置和开发者模式开关。

## 创作台流程

创作台普通模式固定四步：

1. 视频资料：填写视频主题、内容类型、标题草稿、简介草稿、文稿和字幕。
2. 发布方案：生成标题、简介、标签、分区和修改建议。
3. 观众反馈：通过 BV/链接、文件上传或手动粘贴导入评论弹幕。
4. 复盘报告：查看观众关注、误解、争议、下一期选题和互动建议。

## 开发者模式

开发者模式是前端本地开关，存储键为 `link-agent-developer-mode`。

关闭时隐藏：

- 发布方案处理记录和步骤详情。
- API 开销统计。
- 评测样例入口。
- 证据索引状态与重建入口。
- 参考案例检索策略、精排和索引状态。
- AI 浮窗执行模式和推理轨迹。

开启时保留上述诊断能力，便于继续验证后端链路。

## 项目列表联动

项目列表页不直接持有创作台状态。点击继续复盘时写入 `link-agent-creator-workspace`，创作台挂载后复用原有恢复逻辑加载当前项目。

这样做是为了避免 P0 引入新的全局状态管理，同时保持项目列表作为一级入口。
