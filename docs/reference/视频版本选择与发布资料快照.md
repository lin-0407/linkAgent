# 视频版本选择与发布资料快照

实现与实际测试命令见 [S1 闭环说明](../develop/视频自动制作-S1版本上下文与历史选版闭环.md)。本轮源码尚未部署，页面操作未做真实浏览器验收。

成片试映页增加视频版本列表。新视频上传完整后成为当前版，原片、原试映和原版本号保留。“上传新版本”是增加版本；视频已经正式发布或存在 BV 关联时，沿用新建修订任务的规则。

选回历史版需要该版媒体仍存在、保存了可信制作依据，并已完成匹配的视频处理和试映。上传、预处理或试映仍在执行时先完成或取消。只有历史信息、没有原制作依据的旧版仍可查询，不能用当前方案猜测其历史后直接选回。

选择历史版不会覆盖最新候选的任务材料和蓝图，也不改变正式 BV 的版本归属。当前试映页随后按选中的视频恢复媒体和报告；自动制作工程编辑器尚待后续阶段。

绑定 BV 时保存精确版本；归属核验通过时冻结当次可读取的 B 站公开标题、简介、分区和标签。缺失字段明确未知。重同步可以更新播放、点赞等指标和其同步时间，不改写已冻结文案。反馈、竞品和总体复盘使用这一读取口径；它不能证明已发布视频本体内容与文案完全相符。

历史 BOUND 记录如果没有明确版本或冻结文案，不自动从当前视频/当前缓存回填。后续同步出现 UID 异常不会抹除新链路已经保存的永久发布事实，也不能借此重新定位或覆盖原绑定。

开发接口均使用个人工作台默认归属，返回中不包含私有桶、对象键和签名：

| 接口 | 用途 |
|---|---|
| `GET /api/creator/tasks/{taskId}/creation` | 只读当前指针、修订号、正式发布版本和所选版本冻结资料 |
| `GET /api/creator/tasks/{taskId}/creation/versions?page=1&pageSize=20` | 已完成视频历史；最多 100 条/页；包含不可选原因对应事实 |
| `POST /api/creator/tasks/{taskId}/creation/versions/{versionId}:select` | 正文 `{"expectedWorkspaceRevision": 3}`；冲突返回 409，刷新后重新选择 |

部署前需要在备份后的目标库执行统一 `backend/src/main/resources/sql/init.sql` 中的增量建表和补列，并重新构建后端/前端；本轮未对作者现有库执行。发布快照补列分支在隔离旧表上验证可重复执行且原行保持未知，不能当成业务库已经升级。
