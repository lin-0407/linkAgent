# 基础架构与前端主题说明

## 一、MVC 架构约定

### 分层职责

| 层 | 职责 |
|---|---|
| controller | 接收请求、返回响应。 |
| service | 业务规则、状态流转、流程编排。 |
| mapper | 数据库读写。 |
| dto / model | 接口传输和业务数据结构。 |

### 业务域分包

创作者相关功能按业务域拆分为独立子包，每个子包内部再按 MVC 分层：

- `creator.task` — 创作任务管理。
- `creator.suggestion` — 发布前优化建议。

### 适用范围

MVC 分层主要用于 Web 接口和创作者业务模块。`core`、`memory`、`tool`、`llm` 属于 Agent 底座能力，不按传统 MVC 强行重排。

## 二、前端主题系统

### 定位

服务于作品集项目首页，定位为"企业级 ReAct Agent 工作台"。页面第一印象需体现技术密度、调试感和视觉记忆点。

### 色彩规则

**主色：**

- 石榴红 `#E72D48` — 核心品牌色。
- 雾粉桃 `#F1DDDF` — 柔和辅助面。

**辅助色：**

- 墨色 — 文字、深色控制台区域、投影锚点。
- 青绿 — 工具标识、状态指示、可交互焦点，用于打破红粉配色的单一感。
- 金色 — 局部强调与运行态能量感。

### 布局规则

- 首页采用左侧控制台 + 右侧工作台的双栏结构。
- 左侧侧边栏承载品牌标识、会话列表和运行状态。
- 右侧工作台承载顶部指标、消息列表、错误提示和输入区。
- 空态使用斜切撞色卡面和 CSS 几何视觉，避免普通卡片风格。

### 复用约定

新增页面时优先复用 `src/styles/theme.css` 中的 CSS 变量，保持石榴红/雾粉桃的强切面构图、墨色控制台区与白色半透明内容区的对比、方角/小圆角/硬投影/斜切条纹风格。

### 约束

- 不引入新的全局主色，仅允许小面积状态色。
- 不使用大面积紫色、蓝紫渐变或玻璃拟态覆盖当前风格。
- 不按页面独立重写视觉系统。

## 三、前端 P0 用户化重构

### 一级导航

| 页面 | 功能 |
|---|---|
| 创作台 | 当前视频项目的四步主流程。 |
| 参考案例 | 查找可借鉴的视频案例。 |
| 项目列表 | 继续历史视频项目。 |
| 设置 | 普通设置和开发者模式开关。 |

### 创作台四步流程

1. **视频资料** — 填写视频主题、内容类型、标题草稿、简介草稿、文稿和字幕。
2. **发布方案** — 生成标题、简介、标签、分区和修改建议。
3. **观众反馈** — 通过 BV/链接、文件上传或手动粘贴导入评论弹幕。
4. **复盘报告** — 查看观众关注、误解、争议、下一期选题和互动建议。

### 开发者模式

前端本地开关，存储键为 `link-agent-developer-mode`。

关闭时隐藏的诊断入口：发布方案处理记录与步骤详情、API 开销统计、评测样例入口、证据索引状态与重建入口、参考案例检索策略/精排/索引状态、AI 浮窗执行模式和推理轨迹。开启时保留上述诊断能力以供后端链路验证。

### 项目列表联动

项目列表页不直接持有创作台状态。点击继续复盘时写入 `link-agent-creator-workspace`，创作台挂载后复用原有恢复逻辑加载当前项目。此设计避免 P0 引入新的全局状态管理。

## 四、前端 P0-4 视觉与响应式收口

### 范围

收口创作台的前端视觉一致性和移动端可用性，不涉及新增后端能力。

### 用户侧变化

1. 移动端创作台顶部展示当前步骤序号、步骤总数和进度条。
2. 移动端步骤导航改为横向可滑动的轻量步骤条，避免左侧栏挤压表单。
3. 按钮触控区域统一不小于 44px。
4. 长文本结果块和任务项自动换行，降低横向滚动风险。

### 实现要点

**步骤元信息：** `CreatorWorkspace.vue` 增加 `creatorStepMetas`，统一维护普通创作者路径的四个步骤。`activeCreatorStepIndex` 根据 `activeStep` 推导当前步骤索引。当 `activeStep` 为开发者辅助入口 `usage` 时，移动端进度条保持在复盘报告阶段，避免流程被扩成五步。

**移动端进度条：** `CreatorWorkspace.vue` 流程栏中增加 `.creator-mobile-progress` 结构，默认隐藏，仅在窄屏断点下显示。进度条宽度由 CSS 自定义属性 `--creator-progress-percent` 控制。

**响应式覆盖规则：** `theme.css` 末尾集中处理：
- 创作台根容器禁止横向溢出。
- 常用容器和结果块圆角统一。
- 常用按钮和步骤按钮触控高度统一。
- Grid/Flex 子项补充 `min-width: 0`。
- 480px 以下关键网格收为单列。

### 验收口径

| 宽度 | 验收重点 |
|---|---|
| 375px | 无横向滚动；顶部进度条可见；按钮易点击。 |
| 768px | 步骤区不挤压表单；结果块文本不撑破页面。 |
| 1440px | 桌面端左侧流程栏和右侧主内容保持稳定。 |
