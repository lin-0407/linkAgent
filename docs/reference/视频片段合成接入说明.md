# 视频片段合成接入说明

日期：2026-10-20。S4a 内部能力，产品页面尚未开放。功能范围见 [开发说明](../develop/视频自动制作-S4a视频片段合成基础.md)。

## 工程例子

原 `schemaVersion=1` 图文工程无需改动。新工程使用 `schemaVersion=2`，顶层、video、assets 和哈希算法沿用原格式。例如场景截取片段的第 1–3 秒，在 24fps 下占 48 帧：

```json
{
  "id": "scene-1", "startFrame": 0, "endFrame": 48,
  "layout": "VIDEO_CLIP", "background": "#102030",
  "title": "录屏演示", "body": [], "voice": null,
  "clip": {
    "assetId": "screen-1", "sourceStartMs": 1000, "sourceEndMs": 3000,
    "fit": "CONTAIN", "audioMode": "ORIGINAL", "gainDb": -3
  }
}
```

对应本地资产：

```json
{"id":"screen-1","path":"assets/screen.mp4","mime":"video/mp4","sha256":"实际文件的64位小写SHA-256"}
```

例子不是完整可执行工程；需补齐原顶层身份、video、字幕和真实资产摘要，再计算整个输入 `inputHash`。路径由可信后端准备，不能让聊天或公开请求指定任意本机文件。

## 声音与字幕

| 需求 | clip.audioMode | voice |
| --- | --- | --- |
| 使用片段原声 | ORIGINAL | null |
| 画面配自己的录音/TTS | MUTE | 原 voice 对象：assetId、offsetMs、gainDb |
| 环境声加旁白 | MIX | 原 voice 对象，原声增益单独明确选择 |
| 安静画面 | MUTE | null |

原声不存在或所截区间内没有原声时，ORIGINAL/MIX 失败并说明原因，不能悄悄改成其他声音方案。全片明确静音时仍编码两声道 AAC，清单峰值/RMS 为零是已选方案；选择了声音却静音仍为失败。

旁白字幕沿用原 cue 格式。只有原声时，`audioAssetId` 引用视频资产，cue 的时间为成片全局毫秒，必须位于实际原声覆盖区间；已验证没有对白时允许 `subtitles=[]`，SRT 仅含空行，不写占位对白。转写与文意仍由后续素材/ASR 服务提供可信依据。

## 内部执行与限制

继续使用原固定工程 `freeze/attach → worker → renderer → 存储 → 视频登记`，V2 的全部内容进入既有摘要与授权绑定。目标输出仍为 720p/1080p、24/25/30fps、H.264/AAC，单场景至多 30 秒、全片至多 180 秒。源片段至多 30 分钟且仍受资产字节上限限制；源帧率至多 60fps，画面及像素比例规范化的中间尺寸均受 800 万像素边界约束。

调用方式仍为 [renderer README](../../renderer/README.md) 中的本地 CLI 和 Java 接口，保留原工作根目录、全新输出目录、字体、离线与超时约束。新产物必须由更新后的 Java 验收器读取；不能把 V2 的清单冒充 V1 输入的结果。

本轮没有数据库 Schema 或公开 HTTP 接口变更，无需作者运行初始化脚本。没有部署到作者服务；本地配置与样例不代表产品已提供素材上传、模型配置或导出按钮。
