# 独立素材导入后端说明

更新：2026-10-21。实现和接口清单见[S4-1 开发记录](../develop/视频自动制作-S4-1独立素材导入.md)。

当前后端可以保存自己的图片、录音、音乐和视频片段。素材不等于成片：不会创建 V1/V2 视频版本、切换当前视频、进入完整试映或放行发布。

接入顺序：

1. 客户端计算完整文件 SHA-256，以独立幂等键创建素材，轮询到 `UPLOADING`。
2. 按返回的 8 MiB 大小切片，申请短签，直接 PUT 到私有存储，原样登记返回的 ETag 和每片字节数。
3. 调用 `:complete`，后台合并、核对完整文件摘要、探测、解码并规范化。刷新通过 `GET /assets/{assetId}` 找回状态和分片。
4. 只有 `READY` 可申请 `:read-url`。NORMALIZED 用于工作预览；图片/视频另有 THUMBNAIL；ORIGINAL 保留用户原文件。
5. `FAILED` 显示 `failureCode/failureMessage`，可以显式 `:retry`；文件本身错误或摘要不符时应使用新素材重新上传。不要循环自动重试。
6. 取消未完成素材后，`cleanupPending=true` 表示还在核对存储收尾。取消不会撤销历史成片，READY 素材也不能用取消接口物理删除。

可接受 PNG/JPEG、WAV/MP3/M4A、受支持的 H.264/HEVC MP4/MOV。裸 AAC、多音轨、HDR 等会明确拒绝或要求先转换，不能把文件扩展名正确视为导入成功。保留片段原声与无声事实，导入音乐尚不等于已接入 BGM 混音。

部署需要已启用的私有媒体存储、统一 SQL 中的新素材表以及可用 FFmpeg/FFprobe。原生准备沿用 `creator.creation.renderer` 下的命令、工作目录和超时配置，不要求开启整片渲染执行器；素材后台扫描间隔配置为 `creator.creation.assets.poll-interval-ms`，默认 2000 毫秒。存储权限需要覆盖准确对象键下的分片创建、列举恢复、合并、撤销及对象读写删除。

当前尚无素材页面、场景编辑、SRT 导入和独立素材移除入口；故事板、样片与模型生成继续按总清单推进。验证是本地真实数据库、兼容 S3 和原生媒体处理，尚未部署或做真实浏览器操作验收。
