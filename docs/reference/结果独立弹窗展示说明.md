# 结果独立弹窗展示说明

## 适用范围

当前结果弹窗承载三类内容：

1. 发布前优化建议。
2. 评论弹幕导入结果和仪表盘。
3. 评论弹幕 AI 分析报告。

## 入口规则

| 入口按钮 | 出现条件 | 展示内容 |
|---|---|---|
| 查看建议 / 查看并确认 | 已生成发布前优化建议 | 内容摘要、标题建议、卖点、风险、标签和确认按钮 |
| 查看导入结果 | 已拉取、导入或解析评论弹幕样例 | 脚本输出文件、导入概览、分类、情绪、关键词和明细 |
| 查看分析结果 | 已生成反馈分析报告 | 整体反馈、情绪、下一期建议、争议点、误解点和互动建议 |

## 交互行为

1. 结果生成成功后会自动打开对应弹窗。
2. 用户关闭弹窗后，可以通过当前阶段内的入口按钮再次打开。
3. 发布前优化结果会在发布前区域显示“发布前 AI 分析结果已生成”入口卡片。
4. 弹窗只展示当前入口对应的阶段结果，不在发布前建议弹窗里混入反馈分析报告。
5. 点击遮罩空白区域或“关闭”按钮可以退出弹窗。
6. 切换任务、创建新任务、重新保存样例会关闭旧结果弹窗，避免跨任务误读。

## 设计边界

1. 不新增路由，原因是当前 MVP 仍以单页工作台为主。
2. 不把结果内容继续放在表单下方，表单区只负责输入和触发。
3. 不新增后端 API，弹窗直接复用当前前端状态里的结果数据。
4. 不隐藏发布前建议确认动作，确认按钮随发布前建议一起放在弹窗中。
