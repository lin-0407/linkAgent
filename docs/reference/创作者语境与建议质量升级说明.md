# 创作者语境与建议质量升级说明

## 功能定位

阶段 4.11 用来提升发布前优化结果质量，让建议从“标题更吸引人、简介更清楚”升级成“为什么当前表达会影响观众决策，以及 UP 主下一步该怎么改”。

本功能不依赖外部平台数据，不接入 RAG，不声称知道 B 站推荐算法。

## 新增响应字段

接口不变：

```http
POST /api/creator/tasks/{taskId}/pre-publish/analyze
GET  /api/creator/tasks/{taskId}/pre-publish/suggestions
```

`CreatorSuggestionResponse` 新增字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `creatorDilemma` | string | 本期创作者最容易纠结或做错的表达问题 |
| `audienceHook` | string | 观众点击、继续观看、收藏或评论的核心动机 |
| `contentPositioning` | string | 本期内容定位和差异化方向 |
| `actionableRevisionPlan` | string(JSON) | 可执行修改计划列表 |

`titleSuggestions` 的单项对象新增字段：

| 字段 | 说明 |
|---|---|
| `viewerPsychology` | 这个标题对应的观众心理 |
| `clickReason` | 观众为什么会点 |
| `trustRisk` | 标题可能损伤信任的点 |
| `bestScenario` | 最适合使用这个标题的场景 |

## 数据库字段

`creator_suggestion` 新增：

| 字段 | 说明 |
|---|---|
| `creator_dilemma` | 创作者困境 |
| `audience_hook` | 观众钩子 |
| `content_positioning` | 内容定位 |
| `actionable_revision_plan` | 可执行修改计划 JSON |

`init.sql` 包含条件式 `ALTER TABLE`，用于给已有本地库补列。

## 前端展示

发布前优化结果弹窗新增展示：

1. 创作者困境。
2. 观众钩子。
3. 内容定位。
4. 可执行修改计划。
5. 标题建议中的观众心理、点击理由、信任风险和适用场景。

旧数据没有新增字段时，页面显示“未解析到...”兜底文案。

## 设计边界

这次升级是 Prompt 与结构化输出升级，不是 RAG。

它解决的是“让模型先学会按创作者语境分析”。后续接入 RAG 时，可以把外部资料、历史案例或评论证据填入这个分析框架，而不是重新发明输出结构。
