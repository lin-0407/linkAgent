# 创作指导可编辑窗口说明

## 功能定位

创作指导编辑窗口用于让 UP 主调整发布前优化和评论弹幕分析中的表达风格、建议侧重点、关注重点与分析顺序。

后端系统提示词不向前端展示，也不允许通过接口替换。角色定义、平台数据边界和 JSON 输出契约统一由后端维护，以避免恶意或误操作导致功能失效。

## 涉及接口

### 发布前优化

```http
POST /api/creator/tasks/{taskId}/pre-publish/analyze
```

可选字段：

```json
{
  "customGuidance": "标题表达克制具体，先总结核心卖点再给出建议",
  "creatorPreference": "创作者偏好",
  "titleStyle": "标题风格",
  "extraRequirement": "额外要求"
}
```

### 评论弹幕分析

```http
POST /api/creator/tasks/{taskId}/feedback/analyze
```

可选字段：

```json
{
  "customGuidance": "先归纳观众关注点，再分析争议和误解",
  "analysisFocus": "分析重点",
  "extraRequirement": "额外要求"
}
```

## 规则

1. `customGuidance` 最长 2000 个字符。
2. 空值表示不添加用户业务指导，固定系统规则仍始终生效。
3. 用户指导仅可影响风格、分析重点、建议倾向和顺序，不可改变角色、固定输出字段或数据边界。
4. 前端将指导内容保存到 `localStorage`，并移除旧版本存储的完整系统提示词。

## 交互说明

1. “创作指导”对应发布前优化场景。
2. “分析指导”对应评论弹幕复盘场景。
3. 指针在输入区域按下后移出窗口再松开，不会误关闭编辑窗口。

## 安全取舍

可编辑内容是业务偏好，而不是模型控制权。即使绕过前端直接请求接口，后端也不会接收可替换系统提示词的字段，从契约层保持结构化解析和平台数据边界稳定。
