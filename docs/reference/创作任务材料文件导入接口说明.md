# 创作任务材料文件导入接口说明

## 功能定位

这个接口用于把用户本地整理好的文本文件导入到已有创作任务的材料里。

它服务的是创作者工作流中的“稿件输入”环节，不负责平台采集、不负责文件版本管理，也不负责二进制附件处理。

当前创建任务页不再提供本地文本文件导入入口。创建任务更偏向“填写任务主题后由 Agent 推荐标题、简介和材料方向”，避免把“已经写好文稿再导入”作为主路径。

这个接口仍作为兼容和备用能力保留，只面向已经存在的创作任务。

## API

### 导入本地文本文件到任务材料

```http
POST /api/creator/tasks/{taskId}/materials/import
Content-Type: multipart/form-data
```

表单字段：

| 字段 | 说明 |
|---|---|
| materialType | 目标材料类型，支持 `TITLE_DRAFT`、`DESCRIPTION_DRAFT`、`MANUSCRIPT`、`SUBTITLE` |
| file | 本地文本文件，当前支持 TXT、MD、SRT、ASS |

## 行为说明

1. 任务必须已经存在。
2. 文件会按 UTF-8 读取。
3. 文件内容如果前后有 BOM 或多余空白，会先做清理。
4. 导入结果会覆盖对应材料。
5. 如果导入内容发生变化，任务状态会回到 `DRAFT`。

## 入参校验

1. `taskId` 不能为空，长度不能超过 64。
2. `materialType` 不能为空，且只能是四类材料之一。
3. 文件不能为空。
4. 文件大小不能超过 5MB。
5. 文件内容长度要和材料类型匹配：
   1. 标题草稿最长 200。
   2. 简介草稿最长 2000。
   3. 文稿最长 20000。
   4. 字幕最长 20000。

## 前端使用方式

### 创建新任务

当前前端创建任务页不提供文件导入入口。

用户应直接填写任务名称、视频类型和必要材料，或在后续创作工作流中根据 Agent 推荐继续完善内容。

### 编辑已有任务

当前主界面暂不暴露材料文件导入控件。

如后续需要恢复“已有任务材料覆盖导入”，应优先放在任务详情或高级操作区，避免干扰创建任务主流程。

## 适用边界

适合：

1. 把本地写好的文稿导入到任务里。
2. 把字幕文件导入到任务里。
3. 用文本文件替换已有材料，继续做发布前优化。

不适合：

1. 二进制文件。
2. 批量文件导入。
3. 平台自动采集。
