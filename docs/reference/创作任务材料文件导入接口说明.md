# 创作任务材料文件导入接口说明

## 功能定位

这个接口用于把用户本地整理好的文本文件导入到已有创作任务的材料里。

它服务的是创作者工作流中的“稿件输入”环节，不负责平台采集、不负责文件版本管理，也不负责二进制附件处理。

前端还有一个不经过本接口的创建态导入：第一次创建任务时还没有 `taskId`，页面会先在浏览器本地读取 TXT、MD、SRT、ASS 文件，把内容填入任务表单；用户点击创建任务后，材料再随创建任务接口一起保存。

## API

### 导入本地文本文件到任务材料

```http
POST /api/creator/tasks/{taskId}/materials/import
Content-Type: multipart/form-data
```

表单字段：

| 字段 | 说明 |
|---|---|
| materialType | 目标材料类型，支持 `TITLE_DRAFT`、`DESCRIPTION_DRAFT`、`MANUSCRIPT`、`SUBTITLE` |
| file | 本地文本文件，当前支持 TXT、MD、SRT、ASS |

## 行为说明

1. 任务必须已经存在。
2. 文件会按 UTF-8 读取。
3. 文件内容如果前后有 BOM 或多余空白，会先做清理。
4. 导入结果会覆盖对应材料。
5. 如果导入内容发生变化，任务状态会回到 `DRAFT`。

## 入参校验

1. `taskId` 不能为空，长度不能超过 64。
2. `materialType` 不能为空，且只能是四类材料之一。
3. 文件不能为空。
4. 文件大小不能超过 5MB。
5. 文件内容长度要和材料类型匹配：
   1. 标题草稿最长 200。
   2. 简介草稿最长 2000。
   3. 文稿最长 20000。
   4. 字幕最长 20000。

## 前端使用方式

### 创建新任务

1. 在任务输入区直接选择目标材料类型。
2. 选择本地文本文件后点击导入到表单。
3. 检查标题、简介、文稿或字幕输入框。
4. 点击创建任务，把表单内容保存到后端。

### 编辑已有任务

1. 在任务编辑模式里先选中已有任务。
2. 选择目标材料类型。
3. 选择本地文本文件后点击导入材料。
4. 导入完成后刷新任务材料，再继续分析。

## 适用边界

适合：

1. 把本地写好的文稿导入到任务里。
2. 把字幕文件导入到任务里。
3. 用文本文件替换已有材料，继续做发布前优化。

不适合：

1. 二进制文件。
2. 批量文件导入。
3. 平台自动采集。
