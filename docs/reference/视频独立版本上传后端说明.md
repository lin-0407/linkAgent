# 视频独立版本上传：当前后端能力

> 对应 [S1a-1 实现与验证](../develop/视频自动制作-S1a-1独立版本上传实现说明.md)。本步为后端基础，没有新增前端操作入口，未部署作者现有服务。

上传新文件仍使用原 `POST /api/creator/tasks/{taskId}/draft-video/uploads` 和 `Idempotency-Key`。一次会话绑定一个 `versionId`，分片、续传、完成均使用该 `uploadSessionId`；上传另一条视频使用新的幂等键，不能把旧会话改成新视频。

完成上传后返回这次会话对应的成片及版本序号。若后来又上传了新版，重放旧会话的完成请求仍返回旧版，不会把当前版本改回去。上传失败或取消保留原当前版本。

开发接入时可以区分以下查询：

| 接口 | 用途 |
|---|---|
| `GET /api/creator/tasks/{taskId}/draft-video/uploads/current` | 恢复尚未结束的上传会话 |
| `GET /api/creator/tasks/{taskId}/draft-video/uploads/{uploadSessionId}` | 读取某次上传的真实状态 |
| `GET /api/creator/tasks/{taskId}/draft-videos/current` | 读取当前完整成片；初次上传尚未完成时可能为 404 |
| `GET /api/creator/tasks/{taskId}/draft-videos/{versionId}` | 精确读取指定版本，不跟随当前选择 |

当前任务仍需满足原发布方案与制作蓝图门禁；已有成片入口使用原显式跳过事实。新版本上传成功后仍要单独探测、预处理和试映。已有 BV 关联或显式发布标记的任务不直接上传替换版，应新建修订任务。

本步尚不提供版本列表、历史选版、自然语言修改或自动出片。原前端完成态仍可能禁用上传按钮；本说明不能作为该页面已经支持“上传新版”的验收依据。

后续已补 [重新定位历史隔离修复](../develop/视频自动制作-S1重新定位历史隔离修复说明.md)：新方向撤下当前指针，保留已完成视频和试映；旧上传请求不能跨越制作上下文。页面的本地续传恢复改为核对后端当前版本，浏览器行为尚未验收。

后续已补 [精确发布版本绑定](../develop/视频自动制作-S1精确发布版本绑定.md)：原 BV 绑定接口请求保持不变，绑定响应增加可空 `publishedVersionId`。用户新建或修正未核验绑定时保存本次通过媒体处理和试映的当前版本。同步只能验证记录的版本；BV、UID 或版本在外部请求期间发生变化时，跳过旧结果并提示重新同步。

历史 BOUND 绑定未记录版本时，响应仍为 `null`，重复请求不回填。历史 WAITING_VERIFY 绑定未记录版本时，同步不会直接推进为 BOUND，需要用户在原绑定入口重新确认 BV；负向校验结果仍会保留。已经有精确 BOUND 版本的任务，其后续媒体门禁读取该版本，缺失时阻断，不回退当前成片。发布文案和制作上下文快照仍待实施。
