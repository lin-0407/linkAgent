# AI 交互台浮窗说明

## 功能定位

AI 交互台浮窗是创作工作台上的通用 Agent 咨询入口。它保留原通用 Agent 的会话记忆、工具调用和推理轨迹展示能力，但不要求用户离开当前创作页面。

## 使用方式

1. 进入创作工作台后，浮窗默认打开。
2. 拖动顶部标题栏可以移动窗口。
3. 拖动右下角手柄可以调整窗口大小。
4. 点击“收起”可以最小化到标题栏。
5. 点击“关闭”后，通过右下角“AI 交互台”按钮重新打开。
6. 点击“会话”可以查看并切换历史会话。
7. 点击“新建”可以开始新的 Agent 会话。

## 技术实现

核心组件：

| 文件 | 说明 |
|---|---|
| `src/components/AgentFloatingWindow.vue` | 浮窗主体 |
| `src/composables/useAgentChat.ts` | 复用的 Agent 聊天状态与接口调用 |
| `src/components/MessageBubble.vue` | 复用的消息气泡 |
| `src/components/ChatComposer.vue` | 复用的输入区 |

浮窗只在创作工作台模式下挂载，避免和原 Agent 控制台页面同时创建两套聊天状态。

## 尺寸边界

| 项 | 值 |
|---|---|
| 最小宽度 | 420px |
| 最小高度 | 420px |
| 最大宽度 | 920px |
| 最大高度 | 760px |
| 视口边距 | 18px |

尺寸边界在脚本层统一处理，而不是只依赖 CSS。原因是拖动和缩放都需要实时计算窗口位置，脚本层约束可以同时保证大小和位置不会失控。

## 当前限制

1. 暂未做移动端专项适配。
2. 暂未持久化浮窗位置和尺寸。
3. 当前是通用 Agent 咨询入口，暂未自动注入当前创作任务上下文。
