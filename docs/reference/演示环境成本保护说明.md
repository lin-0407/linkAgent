# 演示环境成本保护说明

## 功能定位

演示环境成本保护用于限制单次 LLM 请求的输入规模，避免用户在公开演示或本地试用时提交过长材料，导致模型调用成本不可控。

当前保护范围覆盖所有经过 `LLMService` 的能力：

1. 通用聊天接口。
2. ReAct Agent 执行。
3. 发布前优化。
4. 评论弹幕分析与追问。
5. 竞品分析。
6. 创作复盘报告。
7. 长期记忆抽取。

## 配置项

| 配置项 | 环境变量 | 默认值 | 说明 |
|---|---|---|---|
| `agent.llm.guard.enabled` | `LLM_GUARD_ENABLED` | `true` | 是否开启单次输入规模保护 |
| `agent.llm.guard.max-prompt-chars` | `LLM_GUARD_MAX_PROMPT_CHARS` | `30000` | `system prompt + user prompt` 最大字符数 |

Docker Compose 演示环境已暴露这两个变量。

说明：如果字符上限误配成 `0` 或负数，后端会按最小 `1` 个字符处理。关闭保护必须显式设置 `LLM_GUARD_ENABLED=false`。

## 超限行为

当输入超过限制时，后端返回：

```text
400 BAD_REQUEST
```

错误信息会提示用户先精简文稿、评论或弹幕样例后重试。

## 为什么先用字符数

项目当前目标是作品集演示和学习闭环，优先把风险边界跑通。字符数保护虽然不是精确 token 统计，但具备三个优点：

1. 不引入额外依赖。
2. 不绑定某个模型供应商的 tokenizer。
3. 能提前拦住绝大多数明显超长输入。

如果后续要做多模型成本对比，再把字符数保护升级为 token 估算或供应商返回 usage 记录。

## 推荐配置

本地学习：

```text
LLM_GUARD_ENABLED=true
LLM_GUARD_MAX_PROMPT_CHARS=30000
```

公开演示：

```text
LLM_GUARD_ENABLED=true
LLM_GUARD_MAX_PROMPT_CHARS=12000
```

调试长样例：

```text
LLM_GUARD_ENABLED=false
```

说明：关闭保护只建议在本地临时调试使用，不建议用于公开演示。
