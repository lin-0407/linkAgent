# 后端固定工程渲染接入说明

S3a 负责进程调用与本地产物接收。Java 可以真正启动 S2 渲染器并核验结果；后续 S3b 已补充 [系统产物保存与版本登记](系统成片保存与版本登记说明.md)。尚无用户制作按钮或持久化渲染 worker，运行查询仍为 `executionAvailable=false`。

## 视频实际怎样制作

1. 将文稿拆成场景，工程 JSON 指定标题、正文、图片、布局和起止帧。目前验收工程由预置脚本生成，尚未由模型自动写稿。
2. 样例通过 Windows 离线语音把每句文稿变成 WAV。根据实际音频采样数计算字幕时间和场景长度，不按字数猜时长。这是验收素材制作流程，渲染器本身不调用 TTS。
3. Python Pillow 按帧绘制标题、图片、背景和字幕。固定工程不执行用户代码，画面采用四种受控布局；NumPy 处理音轨采样率、声道和音量。
4. 将 RGB 帧流和完整音轨送入 FFmpeg，编码为 H.264/AAC MP4，同时导出 SRT 和封面。84.167 秒样例采用 24fps，共 2020 帧。
5. FFprobe 检查真实帧数、画幅、帧率和时长；FFmpeg 整片解码、提取音轨及首中尾画面；最后写文件大小与 SHA-256 清单。
6. S3a 的 Java 桥接核验本次运行归属、完整产物和媒体检查事实。S3b 增加存储上传与回读校验、独立版本注册；完整试映仍待后续 S3 子步骤接入。

因此当前视频属于程序合成的图文旁白视频。图片、文字与音频都来自工程声明的本地文件；没有把整个画面交给视频生成模型。后续 S4 才把模型生成的脚本、分镜和真实 TTS 接到同一份工程上。

## 内部调用契约

部署配置前缀为 `creator.creation.renderer`，字段见 `FixedProjectRendererProperties`：

| 配置 | 默认值 | 含义 |
| --- | --- | --- |
| enabled | false | 默认不开启；不改变现有部署 |
| python-path | python3 | 可信解释器名称或绝对路径 |
| module-root | /opt/renderer | 包含 linkagent_renderer 的安装目录 |
| work-root | /tmp/linkagent-creation | 后端独占的制作工作根目录 |
| font-path | /usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc | 部署中文字体 |
| ffmpeg-path / ffprobe-path | ffmpeg / ffprobe | 固定媒体工具 |
| timeout | 600s | 整次调用上限，必须大于零且不超过一小时 |

现有后端镜像未安装全部 S2 Python 库和中文字体，不能只打开开关就认为部署完成。接入时需准备与 S2 一致的本地运行环境；本轮未修改现有镜像或 Compose 服务。

worker 应为每个租约代数分配新的 attemptId，准备：

```text
<work-root>/<runId>/<attemptId>/input.json
<work-root>/<runId>/<attemptId>/assets/...
```

调用 `FixedProjectRenderService.render(Request, BooleanSupplier)`，Request 显式携带 input 路径、runId、attemptId、storyboardId 和 inputHash。身份必须来自已受理运行；不能从未知 JSON 反向推断为已授权运行。

调用期间不得持有数据库事务。取消回调读取本地取消/失租标志；未来 worker 仍需独立心跳和落库前租约代数复核。此桥接不承担持久化调度或替调用者授权。

输出固定在本次目录的 `rendered/`，目录已存在就拒绝。返回八个已核验文件：MP4、SRT、封面、三张实际抽帧、日志和清单；每项包含可信本地路径、大小、SHA-256 和 Content-Type。返回值只证明本地技术验收，不会自动更新任务或试映状态。

## 失败与恢复

取消、线程中断或超时会终止本次进程树；读取进程输出最多保留 64KiB，超过即失败。命令使用参数数组，子进程只保留系统运行环境，不继承业务密钥和 Python 导入设置。

非零退出、退出零却缺失产物、身份不符、工程文件在执行期间变化、文件篡改、缺失、软链接、非法媒体参数和未通过完整解码检查都不能返回成功。异常不回显完整子进程输出或部署路径。

失败目录可用于定位问题，重试必须使用新 attemptId。工程源文件和旧产物不会被本服务覆盖或删除。业务运行是否可恢复、何时上传和注册版本，由后续 worker 协议决定。
