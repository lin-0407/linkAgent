# 自动制作蓝图接入说明

日期：2026-10-20。S3d 内部能力，尚未开放产品入口或部署；`executionAvailable=false`。实现见 [开发说明](../develop/视频自动制作-S3d真实产物驱动自动蓝图.md)。

## 内部调用顺序

1. 通过现有工作流取得当前真实发布方案确认，准备已经验收的固定工程、故事板及内容摘要。
2. 调用 `AutomaticProductionPlanService.start(taskId, ownerId, key, expectedRevision, request, maxCost)`，原子建立专属蓝图并受理整片运行。缺少工作区预算、修订不匹配或授权条件不满足时沿用现有冲突规则。
3. 按受理的运行身份准备源工程，调用既有 `freeze/attach`；未附加工程不会被后台执行。受理与文件附加仍是两个步骤，尚无公开一键原子入口。
4. 原固定执行器领取、续租、制作、验收与存储。保存服务负责写入系统步骤证据，调用者不逐项勾选步骤，也不能直接用存储成功响应替代对象内容核验。
5. 登记 UPLOADED 视频，等待该精确版本的媒体处理。不能把蓝图六步完成解释为试映通过或可直接发布。

相同幂等键与相同输入可恢复受理，包括原修订号和原费用上限。需要改变内容时使用新操作身份；运行冲突仍由已有单活动运行规则阻断。

## 状态与故障

受理成功只完成“内容与工程已确认”。其他步骤起初为 PENDING；失败或取消时保留已发生事实，其余步骤不会自动完成。一个步骤已完成仅说明对应证据实际发生，不代表其后的存储、试映或发布一定成功。

本地完成、上传失败时可以看到本地制作证据，但没有 SAVED 证据就不能登记视频。接管必须以新代数和尝试重新取得所需证据；旧执行者无法补写。已登记视频恢复仍读取同一版本，不依赖旧本地目录，也不再制作或上传一份视频。

原人工制作蓝图、已有成片直接试映和手工步骤更新保持原规则。只有绑定本次系统运行的步骤禁止手工完成/跳过。

## 环境与未完成项

统一 Schema 新增 `creator_creation_auto_step`。本轮仅在新建隔离测试数据库执行；未更新作者当前数据库。正式环境更新须在部署时按统一 SQL 和备份安排执行，不能直接把整份初始化脚本当作无损升级命令。

Python、FFmpeg、字体、工作目录、私有存储和 worker 配置沿用 [S3c 接入说明](固定工程后台执行接入说明.md)，没有新供应商配置。现有部分上传的未登记对象回收和工作目录保留策略仍未收尾。

尚未完成自动探测/预处理/完整试映调度、最终发布包、费用全面归并、浏览器入口及生产部署。真实验证与协议替身的范围见 [验证记录](../error/自动蓝图S3d验证记录.md)。
