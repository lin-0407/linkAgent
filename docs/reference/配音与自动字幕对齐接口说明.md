# 配音与自动字幕对齐接口说明

更新：2026-10-21。对应 S4-3b，开发边界见[实现说明](../develop/视频自动制作-S4-3b配音与自动字幕对齐.md)，上游简报/故事板见[S4-2 接口](简报故事板与工程接口说明.md)，音乐与用户 SRT 见[S4-3a 接口](音乐字幕与时长建议接口说明.md)。当前只有后端接口，没有制作页面。

统一前缀为 `/api/creator/tasks/{taskId}/creation`，沿用个人自托管工作台的 `default` 归属，要求 `creator.media.enabled=true`。真正调用供应商还需要 `creator.creation.voice.enabled=true`、模型与音色配置，以及媒体模块已配置的 DashScope 密钥。

## 查询配音估算

```text
GET /storyboards/{storyboardId}/voice:estimate
```

只读接口：不创建运行、不消耗修订、不产生费用。只统计 `audioMode=TTS` 的场景；故事板里没有 TTS 场景、简报声音选择不是 TTS、供应商未配置时，返回 `blockers` 说明原因。

```json
{
  "storyboardId": "board-id",
  "briefId": "brief-id",
  "configured": true,
  "model": "cosyvoice-v2",
  "voice": "longxiaochun_v2",
  "asrModel": "qwen3-asr-flash-filetrans",
  "sceneCount": 1,
  "totalCharacters": 18,
  "usdToCny": 7.20,
  "estimatedMaxAdditionalCostCny": 0.004385,
  "basis": "CONFIGURED_ESTIMATE",
  "scenes": [
    {
      "sceneId": "opening",
      "characters": 18,
      "textSha256": "…",
      "sceneDurationMs": 3000,
      "ttsUsdUpperBound": 0.000504,
      "asrUsdUpperBound": 0.000105
    }
  ],
  "blockers": []
}
```

`estimatedMaxAdditionalCostCny` 是配置单价的保守上界，不是供应商账单。ASR 秒数按场景帧长计，因为音频放不进镜头时不会提交转写。

## 受理配音准备

```text
POST /storyboards/{storyboardId}/voice
Idempotency-Key: 本次配音请求的独立键
Content-Type: application/json
```

```json
{
  "expectedWorkspaceRevision": 12,
  "maxAdditionalCostCny": 0.500000
}
```

`maxAdditionalCostCny` 不得低于估算上界；低于时返回 409 并提示先查询估算。受理成功返回 HTTP 202：

```json
{
  "runId": "…",
  "runStatus": "QUEUED",
  "runStage": "QUEUED",
  "sourceStoryboardId": "board-id",
  "storyboardId": null,
  "requiresUserDecision": false,
  "scenes": [
    {
      "sceneId": "opening",
      "position": 0,
      "status": "QUEUED",
      "characters": 18,
      "sceneDurationMs": 3000,
      "audioAssetId": null,
      "audioDurationMs": null,
      "audioSha256": null,
      "matchRatio": null,
      "errorCode": null,
      "expectedText": "用户确认的文稿",
      "transcriptText": null,
      "proposals": []
    }
  ],
  "proposals": []
}
```

运行沿用现有 `PREPARE` 类型与 `PREPARATION` 授权；预算、单活动运行、发布后互斥和活动媒体任务门禁都按原规则生效。取消使用：

```text
POST /creation/runs/{runId}:cancel
```

同键重放必须使用相同的 `expectedWorkspaceRevision` 和金额；更换故事板、修订或金额会被拒绝。

## 查询准备结果

```text
GET /voice-preparations/{runId}
```

返回结构同受理响应。`runStatus` 进入终态后仍可查询，用于读取场景结果、提案和最终故事板标识。

| 场景状态 | 含义 |
| --- | --- |
| `QUEUED` | 尚未开始 |
| `SYNTHESIZING` | 已占用场景，正在调用语音合成 |
| `SYNTHESIZED` | 音频已保存并复核，等待转写 |
| `TRANSCRIBING` | 已提交转写，轮询中；重启后按保存的任务标识续查 |
| `ALIGNED` | 转写时间与文稿核对通过，已用于新故事板 |
| `NEEDS_REVIEW` | 需要作者选择：音频超出镜头、文稿不一致、无人声或字幕超限 |
| `FAILED` | 供应商、存储或费用校验失败；`errorCode` 给出受控原因 |
| `CANCELLED` | 运行取消或结束时仍未开始 |

当所有 TTS 场景都是 `ALIGNED` 时，`storyboardId` 是新版本，`parentStoryboardId` 指向发起配音的版本，`document.subtitleTimingSource=ASR_ALIGNED`。任何一个场景是 `NEEDS_REVIEW` 时不会保存新版本，`proposals` 给作者选择；任何技术失败会让运行失败并保留已产生的费用事实。

## 提案代码

| 代码 | 含义与作者需要做的选择 |
| --- | --- |
| `EXTEND_SCENE` | 实际音频比场景长；`proposedDurationMs` 是量化后的可用场景长度，作者需延长场景并重新确认全片时长，或缩短文稿后重新生成 |
| `VOICE_SCRIPT_CONFIRM` | 转写文本与文稿相似度低于阈值；确认是否念对，或改文稿后重新生成 |
| `VOICE_REGENERATE` | 无人声或字幕无法绑定；检查文稿/音色后重新生成 |

音频比场景短时不会阻塞，直接按实际音频对齐；“可缩短场景或保留画面留白”的建议仍由 `GET /storyboards/{id}/timing` 给出，两个接口的提案不要混为一谈。

提案不会自动执行。改场景需要新故事板，改目标总长需要新简报，之后重新估算并授权。

## 受控错误码

| `errorCode` | 触发条件 | 费用处理 |
| --- | --- | --- |
| `VOICE_TTS_RESULT_UNKNOWN` | 上次已发送合成请求但没有音频事实 | 该调用保持 `UNKNOWN`，不重发 |
| `VOICE_TTS_REJECTED` | 供应商明确 4xx 拒绝，未生成音频 | 按 0 结算，不占用后续额度 |
| `VOICE_ASR_RESULT_UNKNOWN` | 上次已发送转写请求但没有任务标识 | `UNKNOWN`，不重发 |
| `VOICE_ASR_SUBMIT_UNCERTAIN` | 转写提交后响应或任务标识保存失败 | `UNKNOWN` |
| `VOICE_ASR_URL_UNAVAILABLE` | 无法为私有音频生成 ASR 短签 | 尚未发送，无费用 |
| `VOICE_ASR_TIMEOUT` | 超过配置的转写等待时间 | `UNKNOWN`，保留任务标识 |
| `VOICE_BUDGET_BLOCKED` | 预算、授权或未知费用阻止新增付费调用 | 未发送的预留会释放 |
| `VOICE_PROVIDER_NOT_CONFIGURED` | 缺少供应商 bean 或配置 | 无调用 |
| `VOICE_STORAGE_NOT_CONFIGURED` | 私有存储桶未配置 | 无调用 |
| `VOICE_FORMAT_UNSUPPORTED` | 返回不是 WAV | 已发生的合成费用按字符结算 |
| `VOICE_AUDIO_INVALID` | 无法解码或规范化后无可靠时长 | 同上 |
| `VOICE_AUDIO_TOO_LONG` | 音频超过场景或单场景 30 秒 | 音频保留，不转写 |
| `VOICE_SCRIPT_MISMATCH` | 文稿与转写相似度低于阈值 | 音频保留，不保存新版本 |
| `VOICE_AUDIO_NO_SPEECH` | 转写没有可用语音片段 | 转写费用按返回用量结算 |
| `VOICE_CUE_TEXT_TOO_LONG` | 单条字幕超过 120 字符 | 同上 |
| `VOICE_CUE_COUNT_EXCEEDED` | 单场景字幕超过 100 条 | 同上 |
| `VOICE_BOARD_NOT_RENDERABLE` | 新故事板未通过工程检查 | 不保存版本 |
| `VOICE_BOARD_SAVE_FAILED` | 保存版本时被并发或来源校验拒绝 | 不保存版本 |
| `VOICE_RUN_FAILED` | 运行失败后仍未完成的场景统一收口 | — |
| `VOICE_CHARGE_MISSING` / `VOICE_PRICE_SNAPSHOT_INVALID` | 费用预留或价格快照缺失、损坏 | 不猜测金额，运行失败待人工核对 |

已发送调用的金额不会因为取消或失败被抹掉。存在 `UNKNOWN` 时，后续新增付费调用会暂停，直到作者核对。只有供应商明确的 4xx 拒绝才按 0 结算；超时、连接中断、5xx 和结果丢失都保留 `UNKNOWN`。结算单价来自预留时写入的价格快照，不随后续部署配置变化。

## 素材与版本

生成的配音是 `kind=NARRATION`、`status=READY` 的独立素材，可用 S4-1 的素材接口查看和读取；`metadata_json.generated` 记录 `kind=TTS`、供应商、模型、音色、文稿摘要、字符数、运行、场景和来源故事板。素材不在简报 `assetIds` 范围内，只允许被 TTS 场景引用。

修改文稿后旧音频摘要不再匹配，编译器返回 `TTS_TEXT_MISMATCH`，必须重新生成；用户录音场景引用生成素材会被 `NARRATION_ASSET_GENERATED` 拒绝。旧故事板、旧音频和引用历史都保留，不做原地覆盖。

## 当前尚未提供

真实 TTS/ASR 供应商验收、真实账单核对、页面操作、多音色选择、环境声独立混音、完整时间线重排与采纳流程、SAMPLE 样片、AI 视频生成和局部修改都不在本接口范围内。后端能力不等于浏览器端到端制作已验收。
