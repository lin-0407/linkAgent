# 固定工程离线渲染说明

当前新增的是 S2 的本地媒体生成工具。它能把已给定脚本、图片、真实音频和时间线渲染成视频；不是一句话自动生成视频，也没有接入现有工作台的制作按钮、版本库或试映状态。

完整契约、固定 CLI、安装与样例生成步骤见 [renderer/README](../../renderer/README.md)。核心流程：

1. 上游提供本地 WAV、PNG/JPEG 及其 SHA-256，生成连续帧区间和绑定实际音频的字幕。
2. renderer 检查输入摘要、归属标识、真实路径、素材格式、音频时长、字体和布局。
3. 按场景写音轨、按帧流式编码，字幕和独立 SRT 来自同一 cue。
4. 对真实 MP4 做 FFprobe、整片解码、解码声音分析和首中尾抽帧。
5. 所有本地检查成功后，最后写出 manifest.json；其中每个固定相对文件名都有大小和 SHA-256。

总时长由实际总帧数和 fps 指定，支持 720p/1080p、24/25/30fps、1–180 秒。旁白放不进场景时拒绝，不能通过截词或加速偷偷满足目标。V1 暂时只做无重叠直切，不能上传自定义 FFmpeg 参数、执行脚本或转场滤镜。

没有 BGM 时使用干净旁白；程序不去下载音乐或临时调用配音。样例用 Windows 本机离线语音，其声源、文本、语速和单句采样范围都有本地记录，仅用于验收，不能当作产品已有的供应商 TTS 适配。

重试使用新的输出尝试目录。目录已存在、摘要不匹配、缺字、文字溢出、旁白越界和不支持的素材会明确失败。只有视频文件而没有有效 manifest.json 时不能当成完整产物。错误退出后清理本次内部临时文件，不修改原始素材和已完成尝试。

建议通过独立容器运行，禁网、只读根文件系统、仅挂载专属工作根目录，并设置 512MiB 内存、2 CPU、进程数及本次超时。首次构建可按实际网络传 `--build-arg APT_DEBIAN_MIRROR=http://mirrors.ustc.edu.cn`，默认仍为 Debian 官方源，不更改作者系统或业务容器。

字幕文字的语义真实性仍需要上游核实。确定性的本地质量检查只证明工程和实际媒体符合指定约束，不代表观众反馈、事实真实性或完整发布前试映已验证。下一阶段 S3 才把真实产物接入业务 worker、OSS、版本注册、探测及完整试映。
