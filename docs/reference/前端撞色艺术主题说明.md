# 前端撞色艺术主题说明

## 主题定位

当前前端主题服务于作品集项目首页，目标不是普通聊天页面，而是“企业级 ReAct Agent 工作台”。页面需要第一眼体现技术密度、调试感和视觉记忆点。

## 色彩规则

主色：

- 石榴红：`#E72D48`
- 雾粉桃：`#F1DDDF`

辅助色：

- 墨色：用于文字、深色控制台和投影锚点。
- 青绿：用于工具、状态和可交互焦点，避免红粉配色过于单一。
- 金色：用于局部强调和运行态能量感。

## 布局规则

- 首页采用左侧控制台 + 右侧工作台结构。
- 左侧侧边栏承载品牌、会话和运行状态。
- 右侧工作台承载顶部指标、消息列表、错误提示和输入区。
- 空态使用斜切撞色卡面和 CSS 几何视觉，避免普通卡片式 AI 页面。

## 后续页面复用建议

新增首页或新页面时优先复用：

- `src/styles/theme.css` 中的 CSS 变量。
- 石榴红 / 雾粉桃的强切面构图。
- 墨色控制台区和白色半透明内容区的对比。
- 方角、小圆角、硬投影和斜切条纹，不要回到大圆角渐变卡片风格。

## 不建议

- 不建议引入新的全局主色，除非它只作为小面积状态色。
- 不建议用大面积紫色、蓝紫渐变或普通玻璃拟态覆盖当前风格。
- 不建议每个页面重新写一套独立视觉系统。
