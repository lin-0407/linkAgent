# 环境声混音接口说明

更新时间：2026-10-22。对应 S4-3d。背景音乐与用户字幕见 [音乐字幕与时长建议接口说明](音乐字幕与时长建议接口说明.md)，开发边界见 [实现说明](../develop/视频自动制作-S4-3d环境声独立混音.md)。

## 1. 能力范围

| 项目 | 说明 |
| --- | --- |
| 入口 | 保存简报时可选 `ambience` 字段 |
| 结果 | V2 工程多一路 `ambience` 音轨，独立音量与淡入淡出 |
| 是否随对白压低 | **否**。需要压低请用 `backgroundMusic.ducking` |
| 是否循环 | **否**。选区必须覆盖全片，素材不足时拒绝 |
| 费用 | 无。只引用已准备好的本地素材，不调用供应商 |

## 2. 请求字段

在 `POST /api/creator/tasks/{taskId}/creation/briefs` 的请求体中加入：

```json
"ambience": {
  "assetId": "rain-1",
  "sourceInMs": 0,
  "sourceOutMs": 60000,
  "gainDb": -24,
  "fadeInMs": 500,
  "fadeOutMs": 800
}
```

| 字段 | 必填 | 约束 | 说明 |
| --- | --- | --- | --- |
| `assetId` | 是 | `[A-Za-z0-9_-]{1,64}` | 必须在本简报 `assetIds` 内，素材 `READY`、类型 `MUSIC`、`audio/wav` |
| `sourceInMs` | 是 | 0–1200000 | 素材内起点 |
| `sourceOutMs` | 是 | 1–1200000，> `sourceInMs` | 素材内终点；长度须等于全片帧长（±1 帧） |
| `gainDb` | 是 | -36 ~ 0，最多 1 位小数 | 环境声独立音量，建议 -24 左右 |
| `fadeInMs` | 是 | 0–10000 | 淡入，按全片时间轴计算 |
| `fadeOutMs` | 是 | 0–10000 | 淡出，按全片时间轴计算 |

`fadeInMs + fadeOutMs` 不能超过选区长度。

不传 `ambience` 时行为与旧版本一致。

## 3. 与背景音乐的关系

| 组合 | 是否允许 | 说明 |
| --- | --- | --- |
| 只有环境声 | 允许 | 工程只有这一路音频，`expects_audio` 仍为真 |
| 只有背景音乐 | 允许 | 与 S4-3a 相同 |
| 两者都有 | 允许 | 两路独立素材、独立音量，混音顺序为原声/旁白 → 背景音乐 → 环境声 |
| 两者同一素材 | **拒绝** | 返回"环境声与背景音乐不能引用同一素材" |

## 4. 编译后字段

```json
"ambience": {
  "assetId": "rain-1",
  "sourceStartMs": 0,
  "sourceEndMs": 60000,
  "gainDb": -24.0,
  "fadeInMs": 500,
  "fadeOutMs": 800
}
```

注意工程字段是 `sourceStartMs/sourceEndMs`，简报字段是 `sourceInMs/sourceOutMs`，两者不要混用。

## 5. 错误码

出现在 `BoardView.check.problems` 与 `timing` 报告的 `proposals` 中，`sceneId` 为空：

| 代码 | 触发条件 | 处理建议 |
| --- | --- | --- |
| `AMB_MISSING` | 素材不在冻结清单、类型不是 `MUSIC`、不是 `audio/wav` | 重新上传长音频并把它加入简报素材 |
| `AMB_DUPLICATE_SOURCE` | 与 `backgroundMusic` 同一素材 | 换一份环境声素材 |
| `AMB_FORMAT_INVALID` | 非 48 kHz 立体声 PCM16、时长不可靠、超过 20 分钟 | 重新导入并等待规范化完成 |
| `AMB_DURATION_MISMATCH` | 选区长度与全片帧长不一致 | 调整区间或用 `timeline:apply` 让区间随总时长走 |
| `AMB_OUT_OF_RANGE` | 选区终点超过素材真实时长 | 缩短区间或换更长素材 |
| `AMB_MIX_INVALID` | 音量越界、单项或合计淡入淡出越界 | 调整音量/淡入淡出 |

以上问题都会让故事板不可渲染，不会静默截断或跳过环境声。

## 6. 时间线调整

采纳 `EXTEND_SCENE` / `SHORTEN_SCENE` 后：

- 环境声 `sourceInMs` 不变；
- `sourceOutMs` 改为 `sourceInMs + 新总时长`；
- 新终点超过素材真实时长 → 409，要求重新选择区间；
- 响应 `notes` 会写明：`环境声 区间终点已随总时长从 Xms 调整为 Yms`。
