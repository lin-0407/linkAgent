# 创作者视频类型语境库说明

> 对应开发文档：`docs/develop/阶段5.7-创作者视频类型语境库.md`

## 1. 功能定位

创作者视频类型语境库保存的是“某个创作者在某类视频里常用或慎用的表达”。

它服务发布前优化，让 LLM 在生成标题、简介、标签和修改建议时更贴近当前账号与当前视频类型。

它不是平台事实库，也不是评论弹幕证据库。评论和弹幕仍然要走反馈分析与证据检索。

## 2. 核心概念

| 概念 | 说明 |
|---|---|
| 视频类型 | 创作者自定义的内容赛道，例如知识科普、游戏攻略、数码测评 |
| 词条 | 关键词、黑话、梗、标题套路、观众关注点或慎用表达 |
| 权重 | 决定提示词注入优先级，用户保存和接受会提高权重，拒绝会降低权重 |
| `GLOBAL` | 全局通用语境，后续可用于跨类型复用 |

## 3. 词条类型

| 类型 | 用途 |
|---|---|
| `KEYWORD` | 适合当前类型的关键词或标签 |
| `SLANG` | 小圈子黑话 |
| `MEME` | 梗表达 |
| `TABOO` | 慎用或避免表达 |
| `TITLE_PATTERN` | 历史有效标题套路 |
| `AUDIENCE_CONCERN` | 当前类型观众常见关注点 |

## 4. API

### 保存词条

```http
POST /api/creator/context/terms
```

必填字段：

- `videoType`
- `term`

可选字段：

- `userId`
- `termType`
- `polarity`
- `sourceType`
- `sourceTaskId`
- `evidenceText`

同一 `userId + videoType + normalizedTerm + termType` 会去重更新。

### 查询词条

```http
GET /api/creator/context/terms
```

常用参数：

- `userId`
- `videoType`
- `termType`
- `includeDisabled`
- `limit`

### 获取语境包

```http
GET /api/creator/context/bundle
```

返回内容包括：

- 原始词条列表。
- 按类型分组后的关键词、黑话、标题套路、观众关注点、慎用表达。
- `promptContext`，也就是可以直接注入 LLM 的语境摘要。

### 禁用词条

```http
DELETE /api/creator/context/terms/{termId}
```

禁用后词条保留在库里，但不再参与提示词注入。

### 反馈词条

```http
POST /api/creator/context/terms/{termId}/feedback
```

```json
{
  "accepted": true
}
```

`accepted=true` 会提高权重。

`accepted=false` 会降低权重，权重过低时自动禁用。

## 5. 发布前优化接入规则

发布前优化会读取当前任务的 `videoType`。

当偏好模式是 `USE_HISTORY` 时，提示词会同时带入：

- 创作者历史偏好。
- 当前视频类型语境库。

当偏好模式是 `IGNORE_HISTORY` 时，两者都不带入。

当偏好模式是 `EXPERIMENT` 时，两者只作为避坑参考。

## 6. 前端入口

创作工作台有三个入口：

- 任务表单的视频类型选择。
- 发布前优化区域的“类型语境库”预览。
- “管理语境”弹窗。

发布前优化结果弹窗里也可以把这些内容保存为语境：

- 目标受众。
- 观众钩子。
- 标题建议。
- 标签建议。

## 7. 数据库

表：`creator_context_term`

字段注释在 `backend/src/main/resources/sql/init.sql` 中维护。

已有本地库需要重新执行初始化脚本中的兼容 DDL，确保：

- `creator_task.video_type` 存在。
- `creator_context_term` 表存在。

## 8. 使用建议

第一版建议只保存高确定性的内容。

适合保存：

- 用户明确认可的词。
- 多次表现好的标题套路。
- 当前类型观众反复关注的问题。
- 已经证明容易误导观众的慎用表达。

不适合保存：

- 一次性热梗。
- 没有证据的流行词。
- 和当前账号风格冲突的外部话术。
