# 设置面板说明

> 对应开发文档：`docs/develop/阶段5.6-设置面板.md`

## 1. 功能定位

设置面板是面向开发者 / 运维者 / 演示者的全局抽屉。

它集中处理四类信息：

- 运行期可动态修改的开关。
- 启动期配置的只读状态。
- 基础设施连通性检测。
- 知识库索引运维。

入口固定在页面左上角，点击后从右侧打开设置抽屉。

## 2. 动态开关

动态开关覆盖值保存到 `app_runtime_setting` 表，后端业务调用前读取，修改后下一次调用生效。

如果某个 key 还没有写入表，后端会回退到 `application.yml` 或环境变量里的当前配置值。

| 开关 | key | 影响范围 |
|---|---|---|
| LLM 成本保护 | `agent.llm.guard.enabled` | `LLMService` 调模型前是否检查输入长度 |
| 摘要记忆 | `agent.memory.summary.enabled` | `SummaryMemory` 是否读取 / 生成 / 保存摘要 |
| 案例库 rerank 精排 | `knowledge.rag.rerank.enabled` | 案例检索是否扩大候选池并调用 rerank |
| 反馈追问 RAG | `creator.feedback.rag.enabled` | 评论弹幕追问证据是否优先走向量检索 |

动态开关只控制“是否启用”。其他参数仍来自配置文件，例如字符上限、topK、候选池大小。

## 3. 只读状态

以下配置只读展示，因为它们会影响 Spring 启动期 Bean 装配：

| 配置 | 原因 |
|---|---|
| `knowledge.rag.enabled` | 影响知识库 Agent 工具和向量库初始化 |
| `knowledge.rag.hybrid.enabled` | 影响 hybrid 客户端初始化 |
| `agent.kernel.structured.enabled` | 当前通过 `@Value` 启动注入 |
| `agent.memory.short-term.store-type` | `memory / redis` 是启动期 Bean 二选一 |

这些配置需要改配置文件并重启后生效。

## 4. API

### 查询设置状态

```http
GET /api/settings/status
```

响应包含：

- `dynamicToggles`：可动态修改的开关列表。
- `readonlySettings`：只读配置列表。

### 修改动态开关

```http
PUT /api/settings/toggles/{settingKey}
Content-Type: application/json

{
  "enabled": true
}
```

校验规则：

- `settingKey` 不能为空，长度不超过 128。
- `enabled` 必填。
- `settingKey` 必须在服务端白名单里。

### 连通性检测

```http
POST /api/settings/connectivity/check
```

检测项：

- MySQL。
- Redis。
- ChatModel Bean。
- EmbeddingModel Bean。
- 知识库父向量库。
- 知识库子向量库。
- 知识库 hybrid 向量库。

检测不会主动调用 LLM 或 Embedding，避免设置页产生模型成本。

## 5. 前端结构

| 文件 | 说明 |
|---|---|
| `src/components/SettingsDrawer.vue` | 设置抽屉主体 |
| `src/components/KnowledgeIndexPanels.vue` | 知识库索引运维面板 |
| `src/api/settings.ts` | 设置接口客户端 |
| `src/types/settings.ts` | 设置相关类型 |
| `src/App.vue` | 挂载左上角设置入口和全局抽屉 |

案例库页面已移除索引运维面板，只保留采集导入、案例检索和案例列表。

## 6. 数据库

表：`app_runtime_setting`

字段说明见 `backend/src/main/resources/sql/init.sql`。

表默认可以为空。若本地库已存在，需要重新执行初始化脚本中的建表语句，或手动执行阶段 5.6 新增 DDL。
